# 02. Файловая система

Статус: **черновик**, структура каталогов ещё обсуждается (см. [09-open-questions.md](09-open-questions.md)).

## VFS

- Обёртка над `fs` CC, свой слой путей, прав и монтирования.
- Всё в ОС использует VFS. Legacy-процессам подставляется заменённый `fs`.
- `fs` в CC: Tweaked **не поддерживает симлинки** сам по себе. Мы реализуем их в VFS.

## Симлинки

- Ссылка это маленький специальный файл с целевым путём (абсолютным или относительным).
- VFS разворачивает ссылки при обращении.
- Защита от циклов: максимальная глубина 16.
- Битая ссылка даёт понятную ошибку.
- `delete` на ссылке удаляет ссылку, не цель.
- В режиме восстановления (чистый CraftOS) ссылки видны как маленькие файлы.
- Формат файла-ссылки: **(определить)**, например заголовок-магия + путь.

## Шорткаты путей `$name`

Таблица алиасов в `/cube/cfg/paths.json5`. Подстановка в строках путей. Работает во всех API путей и в шелле.

```
$appdata/score.txt      # каталог данных ТЕКУЩЕГО приложения
$home/docs
$backup/worlds
$apps/snake/core
```

Правила:
- `$appdata` разрешается **для каждого приложения отдельно** (изоляция, песочница).
- Алиасы могут ссылаться на другие алиасы. Циклы запрещены.
- Алиасы можно переопределять пользователем. Хранятся отдельно от дефолтов (см. JSON5).
- Весь файл `paths.json5` можно сохранить и восстановить после переустановки.
- Символ `$` принят. Он вводится как Shift+4 на английской раскладке.

Стандартные алиасы (черновик):

| Алиас | Значение |
|---|---|
| `$sys` | `/cube/sys` (read-only) |
| `$lib` | `/cube/lib` |
| `$apps` | `/cube/apps` |
| `$appdata` | `/cube/data/<app-id>` |
| `$home` | `/cube/users/<user>` |
| `$docs`, `$desktop` | подкаталоги `$home` |
| `$temp` | `/cube/tmp` |
| `$trash` | `/cube/trash` |
| `$cfg` | `/cube/cfg` |
| `$mnt` | `/cube/mnt` |

## Структура каталогов (предложение)

```
/                           корень CraftOS
├─ startup.lua              точка входа CubeOS
├─ rom/                     CraftOS (read-only)
└─ cube/
   ├─ boot/                 загрузчик, recovery
   ├─ sys/                  ядро, HAL, сервисы (read-only для приложений)
   ├─ lib/                  стандартная библиотека Cubic/Lua, общие модули
   ├─ bin/                  системные утилиты (командная строка)
   ├─ apps/<id>/            установленные приложения (код, ресурсы)
   ├─ data/<id>/            данные приложений ($appdata)
   ├─ users/<name>/         домашние каталоги (docs, desktop, settings)
   ├─ cfg/                  конфиги: system.json5, paths.json5, assoc.json5, user.json5
   ├─ fonts/  themes/  locale/
   ├─ cache/  tmp/  trash/  log/
   └─ mnt/                  точки монтирования (диски, сетевые)
```

Открытые вопросы: одна или несколько учётных записей, как монтировать `disk`, где лежат игры (в `apps` или отдельно).

## Ассоциации файлов

`/cube/cfg/assoc.json5`: расширение в приложение и иконку. Приложения регистрируют свои расширения при установке `.stp`.

## Корзина

Удаление через файловый менеджер перемещает в `$trash`. Окончательное удаление отдельной командой. Срок хранения и лимит размера настраиваются.
