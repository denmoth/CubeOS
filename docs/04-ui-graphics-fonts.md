# 04. Интерфейс, графика, шрифты

## Два режима

- **Оконный:** оконный менеджер, док/панель, рабочие столы, уведомления.
- **Текстовый:** улучшенный шелл (конвейеры, автодополнение, шорткаты `$`). Подходит для Pocket/Turtle, режима восстановления и работы по сети.

Приложение объявляет в манифесте `ui: window | text | both`. Библиотека интерфейса описывает виджеты один раз и рисует либо окнами, либо TUI. CLI-программы запускаются в обоих режимах (в оконном внутри окна терминала). Переключение горячей клавишей.

## Графика

Единый API `cube.gfx`: примитивы, спрайты, текст, буфер кадра. Бэкенды (см. [01-architecture.md](01-architecture.md)): `cc-graphics`, `teletext`, `text`.

- На teletext включается дизеринг и подбор палитры (`term.setPaletteColor`, 16 цветов из 24 бит).
- Перерисовка инкрементальная (dirty-регионы), не полным кадром.
- API CC: Graphics **(проверить)**.

## Шрифты

- Свой растровый формат `.fnt`. Размеры: 5x7, 6x8, 8x8, пропорциональный.
- Кириллица и латиница обязательны, иконочные глифы.
- Конвертер из BDF/PSF и PNG-атласов отдельной утилитой.
- Сервис `fontd`: кеш глифов, жирный/курсив (синтез), подбор по размеру.
- **Кириллица:** терминал CC по умолчанию кириллицу не показывает **(проверить)**. Нужен собственный рендер глифов (CC: Graphics или teletext-шрифт). Ввод кириллицы с клавиатуры тоже под вопросом **(проверить)**. От этого зависят русский и украинский Wordle.

## Темы

- Темы `.thm` (JSON5): цвета, шрифт, размеры.
- Тёмный/светлый режим.

## Локализация

- Строки в `locale/<lang>.json5`.
- Языки: ru, en, uk (минимум).

## Виджеты

Кнопка, список, поле ввода, вкладки, скролл, диалоги, меню, выпадающий список, таблица. Раскладка flex/grid.

## Панель и меню

Док/панель, часы, сеть, лаунчер с поиском (Ctrl+Space), центр уведомлений, быстрые настройки (громкость, тема), диспетчер задач (процессы, память, события).

## Декларативный язык интерфейсов `.cui`

Решено делать вместе с Cubic (D37). Описывает дерево виджетов, раскладку, привязки к обработчикам на Cubic. Один файл рисуется и окнами, и в текстовом режиме. Пример (черновик):

```
window "Notes" {
  button "Save" onClick=save
  textarea id=body
}
```
