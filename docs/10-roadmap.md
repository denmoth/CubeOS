## Идеи без срока

- **Размытие движения (motion blur) для окон и анимаций.** Пробовали в CGL: затемнение кадра по таблице (след из кругов в местах прошлых кадров) и сплошные мазки между прошлой и новой точкой. Выглядело как гирлянда кругов и работало на 7 кадрах в секунду на большом мониторе, поэтому код вырезан (D173). Для движения окон нужно другое: смешивание двух кадров или размытие по направлению движения на содержимом окна, с настройками (длина, яркость, порог скорости, где включено), а не следы за точками. Заготовки, которые могут пригодиться: затемнение палитры по таблице, палитра со ступенями яркости, `fx.remap` по области.
- Аддон для CC, отправляющий терминал чаще серверного тика (больше 20 видимых кадров); сначала изучить исходники CC:Tweaked и CC:Graphics.
- Стена дисплеев (`cgl.wall`): много узлов, каждый рисует свой кусок одного монитора или отдельные мониторы; проверка параллельности вычислений.
- Проигрыватель видео (`.cvid`, конвертер на ПК, звук DFPWM).

## Программы для проверки совместимости терминала (PineStore)

Для проверки слоя совместимости CraftOS (D184) берём живые программы из PineStore (ставятся командой `wget run https://pinestore.cc/d/<id>`; лицензии на страницах не указаны, поэтому в репозиторий их код не кладём, только запускаем скачанными):

- `sl` (/projects/132): шуточный паровоз по терминалу, самая простая проверка вывода и звука.
- Buckshot Roulette (PineJam 2026, Sima): текстовая игра, музыка через `speaker`.
- CC:Zombies 0.6 (/projects/228): большая игра на палитровых цветах, много места на диске, `speaker`; проверка `term.setPaletteColor` и лимитов места.
- Obsi Game Engine 1.5 (/projects/27): 2D движок с отрисовкой через `pixelbox`, `parea`, `hmon` (мониторы); проверка прямой работы с `term` и мониторами.
- CC:Minecraft (/projects/2) на Pine3D: тяжёлый 3D, проверка скорости `term.blit` и `drawPixels`.
- PixelUI (/projects/154): набор окон и виджетов, `require("pixelui")`; проверка `require`, `package.path`, окон `window`.
- Из PineJam 2026: `bombastic island` (стена мониторов 3x3, ComBox), `4th Dimension` (много звуковых каналов), `Forever Testing` (Pine3D и PinePix, потоки через `parallel`).


## Сверка с документацией (2026-10-14): что ещё нужно не забыть

Найдено при сверке `docs/00-13` с порядком работ. Пункты не потеряны, они привязаны к шагам:

- **Шаг 1, терминал:** legacy-процесс (`term` в окно, `fs` через CFS, чтобы видны симлинки, без `import`); HAL с `gfx.caps()`, `audio.caps()`, `periph.has()` (в доках есть, в коде ещё нет); `require` и `package.path` (нужен PixelUI); проверка события `paste`.
- **Шаг 2, ядро:** журнал `/cubeos/var/log` с уровнями и просмотром; службы `permd`, `notifyd`, `clipboard`, `fontd`, `audiod`, `netd` как манифесты; монтирование дискет и дисков по событиям `disk`, виртуальные `/cubeos/proc`, `/run`, `/hardware`; обработчик сбоев (экран ошибки и запись в журнал); выключение и перезагрузка; часы и часовой пояс.
- **Шаг 3, stew:** пакеты `.cpk`/`.cbx` (двоичная раскладка и подпись ещё не решены, вопросы 8–9), ленивая загрузка из облака (`.cloud`-заглушки, опора №5), версии ОС как пакеты (`kind: "os"`), обновления и откат, адаптер PineStore, рецепты сторонних источников.
- **Шаг 4, ввод и шрифты:** русский ввод. CC доставляет `char` только в диапазоне 32..255, поэтому кириллицу печатать нельзя, пока нет слоя ввода: переводим клавиши `key` в символы по раскладке (ЙЦУКЕН, украинская) с переключением (Ctrl+Shift или Alt+Shift) и индикатором в верхней полосе. Локализация `.lang` (множественные числа, запасные языки), редактор переводов.
- **Шаг 5, CDE:** стабильный контракт между композитором и окружением (D183 делает CDE основным, но контракт нужен для чужих окружений), расслоение API `cube.*` и `ext.<id>.*`, режим совместимости, плитки входа, блокировка экрана и быстрая смена пользователя; буфер обмена с историей, undo/redo, центр уведомлений, корзина; приложения (файловый менеджер, редактор, терминал, настройки, диспетчер задач, конструктор установщиков, архиватор, клиент облака, магазин, калькулятор).
- **Шаг 6, песочница:** манифесты с `permissions` и `caps`, `caps.conf` (по методам, не по типу), `mods.conf`, диалог повышения прав, несовместимые моды (Classic Peripherals).
- **Шаг 9, в конце:** бюджет базы (в `01-architecture.md` написано 250 КБ, теперь цель дискеты 120 КБ, D187: обновить), `.cui` (вопрос 19: скорее всего не нужен, у нас библиотека `ui`), игры (змейка, тетрис, понг, морской бой, шахматы с ботом, Wordle со словарями), Doom из PineStore.
- **Проверки в игре, которые ждут:** событие `paste` (вопрос 3), версия CC, монтирование дискет (вопрос 5), кириллица в вводе (вопрос 26), `http` и лимит дискеты 125 КБ, скорость кадра CGL и `ui`.
- **Устаревшие документы для правки:** `04-ui-graphics-fonts.md` и `11-platform.md` упоминают режимы `window`/`text` как настройку окружения (теперь TUI это терминал, D183–D184), `01-architecture.md` про бюджет 250 КБ.
