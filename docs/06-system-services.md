# 06. Системные сервисы

## Буфер обмена

- **Свой буфер ОС** с историей, общий для всех приложений.
- **Вставка из буфера Windows:** событие `paste` (Ctrl+V). Майнкрафт читает системный буфер и передаёт текст в компьютер. По моим сведениям, CC обрезает вставку **до первой строки и до 512 символов** и фильтрует символы **(проверить)**. Многострочная вставка этим способом невозможна.
- Обход многострочных вставок: мод автора (посимвольный ввод буфера) работает вне ОС. В самой ОС для больших текстов используем Pastebin/Gist.
- **Копирование наружу** (в буфер Windows): API записи нет, насколько известно **(проверить)**. Не требуется.
- Горячие клавиши: Ctrl+C/X/V. Ctrl+T/R/S зарезервированы в CC (прерывание, перезагрузка, выключение), не занимаем.
- Выделение текста мышью через `mouse_drag`.

## Undo/redo

- Общая библиотека истории: команда с `do` и `undo`, стек отката и возврата.
- Группировка правок по времени в редакторе.
- Горячие клавиши Ctrl+Z / Ctrl+Y.
- Для файлового менеджера: корзина (см. [02-filesystem.md](02-filesystem.md)).

## Уведомления

Центр уведомлений, очередь, приоритеты. API `cube.notify`.

## Разрешения

См. [01-architecture.md](01-architecture.md). Сервис `permd` хранит выданные права, показывает диалоги запроса.

## Сеть

- `cube.net` поверх rednet: сервисы по имени, RPC.
- Удалённый рабочий стол и текстовый доступ по сети: на потом.
- HTTP через CC `http` (с учётом настроек сервера).

## Логирование

Уровни DEBUG/INFO/WARN/ERROR/FATAL, файл `/cube/log`, просмотр в диспетчере.

## Настройки

JSON5 с точечной записью значений. Дефолты и пользовательские переопределения раздельно (см. [03-file-formats.md](03-file-formats.md)).

## Обновления

Автообновление и откат на предыдущую версию. Механизм через `.stp`/пакеты.
