# 00. Обзор

## Название и версии

- Система называется просто **CubeOS**, без номера. Выпуски нумеруются по SemVer (первый опубликованный 0.1.0).
- Версии выпусков: **SemVer** `MAJOR.MINOR.PATCH`.
  - MAJOR: несовместимые изменения API или форматов.
  - MINOR: новые возможности с обратной совместимостью.
  - PATCH: исправления.
- Предрелизные метки: `-alpha`, `-beta`, `-rc.N` (например `0.3.0-beta.2`).
- До `1.0.0` формат и API могут меняться без предупреждения.
- Язык программирования **Cubic** ("кубик") версионируется отдельно от ОС. Версия языка пишется в манифесте пакета.

## Цели

1. **Глобальность.** ОС не зависит от сервера, версии мода и конкретных аддонов. Всё, что зависит от аддона, подключается драйвером и имеет запасной вариант.
2. **Удобство разработки.** Свой язык (Cubic), единый API, сборщик, инструменты.
3. **Удобство пользователя.** Оконный и текстовый режимы, буфер обмена, undo/redo, корзина, шорткаты путей.
4. **Открытость.** Магазин приложений на GitHub, подключаемые каталоги, установщики `.stp`.
5. **Надёжность.** Откат в чистый CraftOS, песочница приложений, симлинки и VFS.

## Опоры дизайна

Любая новая идея проверяется на пяти опорах:
1. **Лёгкость:** укладываемся в диск 1 МБ.
2. **Работает без модов:** любой аддон необязателен, у каждой функции есть запасной вариант.
3. **Защита от не-админов** (админы доверенные).
4. **Модульность:** сменные DE и дистрибутивы, стабильный контракт API.
5. **Ленивая загрузка из облака:** заглушки `.cloud`, установлено не значит занимает место.

## Не цели (пока)

- Межсерверная связь (сетевая игра, облако между серверами). Допускается через HTTP, но вне приоритета.
- Защита кода от копирования и обфускация. Мы выбираем открытость. Минификация нужна только для размера.
- Совместимость с CraftOS-программами не отменяется: они запускаются как legacy-процессы.

## Принципы

- **Нет глобальных переменных ядра.** Модули через `import`, окружение процесса изолировано.
- **Встроенные имена защищены** (см. [01-architecture.md](01-architecture.md)).
- **Конфиги в JSON5**, запись значения не стирает комментарии (см. [03-file-formats.md](03-file-formats.md)).
- **Нумерация с 1**, как в Lua. Никаких трансляций индексов.
- **Явное лучше неявного:** разрешения, пути, переопределения.

## Глоссарий

| Термин | Значение |
|---|---|
| CraftOS | Стандартная ОС CC: Tweaked, лежит в основе |
| VFS | Виртуальная файловая система CubeOS (симлинки, шорткаты, монтирование) |
| Cubic | Язык программирования CubeOS, компилируется в Lua |
| `.cub` | Исходник на Cubic |
| `.cpk` | Cube PacKage, пакет приложения (как APK/JAR), работает как exe |
| `.cbx` | Cube BoX, обычный архив |
| `.cloud` | Облачная заглушка файла (Pastebin, Gist, rednet, URL) |
| DE | Окружение рабочего стола (оболочка, панель, оформление) |
| Дистрибутив | Набор пакетов и настроек поверх ОС |
| `.stp` | SeTuP, установщик |
| `$name` | Шорткат пути (например `$appdata`) |
| HAL | Слой драйверов (графика, звук, сеть, ввод) |
| Legacy-процесс | Обычная CraftOS-программа, запущенная внутри CubeOS |

## Аддоны

Поддерживаются через драйверы HAL, у каждого есть запасной вариант:

| Аддон | Что даёт | Без аддона |
|---|---|---|
| CC: Graphics | Пиксельная графика | Субпиксели 2x3 (teletext), потом обычный `term` |
| High Quality Speaker | PCM-аудио | `speaker.playAudio` (DFPWM), `playNote`/`playSound` |
| Advanced Peripherals (идея) | ChatBox, детекторы, мосты | Приложения проверяют `periph.has(...)` |
| Gist/Pastebin/GitHub | Облако, магазин | Только локальное хранилище |

Точные API CC: Graphics и HQ Speaker **(проверить)**, когда дойдём до драйверов.

Идеи дополнительных аддонов: Advanced Peripherals, CC:C Bridge (Create), Tom's Peripherals, Plethora, Peripheralium, CC:VS.
