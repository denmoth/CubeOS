# 07. Встроенные приложения и игры

## Системные приложения

- Файловый менеджер (превью, корзина, симлинки).
- Текстовый редактор (подсветка Lua и Cubic, undo/redo, буфер).
- Терминал (окно).
- Настройки.
- Диспетчер задач.
- Конструктор установщиков `.stp` и дистрибутивов.
- Редактор переводов `.lang` (ключи, перевод рядом с оригиналом, проверка недостающих строк и плейсхолдеров, предпросмотр тегов).
- Архиватор (`.cbx`, `.cpk`).
- Продвинутый pastebin и клиент облака.
- Магазин приложений.
- Калькулятор.

## Игры

Все работают в обоих режимах UI; при наличии CC: Graphics получают пиксельную графику. Выкладываемые игры можно обновлять через магазин независимо от ОС.

### Змейка, Тетрис, Понг, Морской бой

Реализуемы без проблем. Тетрис: 7-bag, hold, "призрак" фигуры.

### Шахматы

- Хот-сит.
- Онлайн по rednet в пределах одного мира/сервера: ход как сообщение, часы, ничья/сдача, зрители.
- Бот с уровнями сложности. Нижний уровень примерно как бот Martin на Chess.com (около 250). Слабые уровни: ограничение глубины, шум оценки, вероятность зевка.
- Верхний уровень: цель около 1650 Эло, но **не гарантирована**. Lua в CC медленный, нет 64-битных битбордов (числа это double, `bit32` 32-битный), на ход есть лимиты по времени. Реалистично на Lua: примерно 1200-1500 **(проверить бенчмарком)**. Запасной вариант: необязательный сильный режим через HTTP.
- Представление доски: массив (0x88 или 10x12), а не битборды.

### Wordle

- Языки: en, ru, uk (минимум). Русский и украинский зависят от кириллицы в терминале (см. [04-ui-graphics-fonts.md](04-ui-graphics-fonts.md)).
- Словари: список ответов (2-3 тыс.) и список допустимых слов (около 12 тыс.), отдельные пакеты на язык. Скачиваются по требованию с кешем (репозиторий магазина, зеркало Pastebin).
- **Слово дня**, не зависящее от сервера: реальная дата UTC через `os.epoch("utc")` **(проверить)**. Индекс = число дней с эпохи по фиксированной перестановке списка ответов. Список только дописывается, чтобы обновление не сдвигало слова. Смещение суток настраиваемое.
- Обычный режим: случайное слово.
