# 08. Журнал решений

Формат: номер, решение, причина. Дата сессии планирования: 2026-10-13.

| # | Решение | Причина |
|---|---|---|
| D1 | ОС называется **CubeOS 2.0** (имя, не версия) | Решение автора, как "Windows 7" |
| D2 | Версии по SemVer, метки `-alpha`/`-beta`/`-rc.N` | Стандарт, понятно |
| D3 | ОС работает поверх CraftOS, использует его как базовый терминал | Исходное требование |
| D4 | Язык **Cubic** (`.cub`), транспиляция в Lua, без VM | Скорость Lua, интеграция с API CC; VM в 30-100 раз медленнее |
| D5 | Отступы вместо `end`, питоноподобный синтаксис | Удобство разработки |
| D6 | Нумерация с 1 | Совместимость с Lua и CC API |
| D7 | Диапазоны `range[a, b)` с математическими скобками | Читаемость; префикс `range` убирает конфликт со списками |
| D8 | Один тип `num`, без `int` | В CC нет целых; Luau тоже |
| D9 | `/` дробное, `//` целочисленное | Предсказуемость |
| D10 | Строгие типы директивами `#!strict` / `#!loose`, переключаемыми | Тяжёлая логика строго, ленивая нестрого |
| D11 | Встроенные `copy` / `deepcopy` | Присваивание таблицы это ссылка, это путает |
| D12 | Защита встроенных имён от перезаписи, `override` для подмены | Lua-глобалы общие на процесс |
| D13 | Исключения `try/except/finally` | Удобство |
| D14 | Модули: относительные, полные, через `$`-шорткаты | Гибкость |
| D15 | Нативные вставки Lua (`lua:`) | Как в Kotlin; доступ к любым возможностям |
| D16 | Комментарии вырезаются, `--keep-comments`; `--minify` для размера | Размер диска; защита кода не цель |
| D17 | Обфускация для защиты от копирования не делаем | CC это open-source сообщество |
| D18 | Конфиги в **JSON5**, запись значения точечная, без потери комментариев | Стандартный формат, готовая поддержка |
| D19 | Свой VFS, симлинки реализуем сами | `fs` CC их не поддерживает |
| D20 | Шорткаты `$name`, `$appdata` у каждого приложения свой | Удобство, песочница, переустановка |
| D21 | Режимы оконный и текстовый | Pocket/Turtle, recovery |
| D22 | Расширения: `.cpk` (пакет), `.stp` (установщик), без префикса `c` у остальных | Автор принял `.cpk`, остальное без приписок |
| D23 | Хранилище с бэкендами: Pastebin, Gist, GitHub, rednet | Нет единственного идеального |
| D24 | Магазин на GitHub (репозиторий, PR), плюс подключаемые каталоги | Просто, версионируется |
| D25 | Межсерверные функции вне приоритета | Автор: пока не нужно |
| D26 | Свой буфер обмена ОС, вставка из Windows через `paste` | Запись в буфер Windows невозможна и не нужна |
| D27 | Undo/redo и корзина в системе | Требование |
| D28 | Игры: шахматы (бот, онлайн по rednet), Wordle (слово дня по UTC), змейка, тетрис, понг, морской бой | Требование |
| D29 | Git-репозиторий обязателен, работа через ветки | См. [dev/git-workflow.md](dev/git-workflow.md) |
| D30 | Прежние наработки (Pastebin Denmoth, в том числе CubeOS 1.x и 2.0) не переиспользуем как код | Автор: "залупа"; берём только идеи (CubePacker, разрешения, события) |
