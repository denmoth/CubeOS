# 03. Форматы файлов

Статус: расширения и общие решения **приняты**, бинарные раскладки в разделах ниже это проект, их детали уточнятся при реализации.

Принцип: отдельное расширение нужно, когда файл должен опознаваться сам по себе (двойной клик, ассоциации, обмен). Но автор решил оставить `.clib` и `.driv`, хотя папка уже задаёт роль.

## `.cloud` (заглушка)

Однострочный текст `ИСТОЧНИК: значение`. Первая строка обязательна, остальные необязательные строки `ключ=значение`.

```
P: 12345gg
```

| Буква | Источник | Значение |
|---|---|---|
| `P` | Pastebin | ID записи |
| `G` | GitHub Gist | `пользователь/id/файл` |
| `R` | rednet-сервер (личный сервер, база) | `имя-компьютера/путь` |
| `C` | свой URL по HTTP(S) | `домен/путь` (схема по умолчанию https) |
| `H` | файл из репозитория GitHub (по желанию) | `пользователь/репо/ветка/путь` |
| `S` | пакет из магазина (по желанию) | `id@версия` |

Дополнительные ключи: `sha256=...`, `size=...`, `ver=...`, `enc=raw|b64|b85` (кодирование для текстовых каналов).

Правила:
- **Для кода хэш обязателен** (`.lua`, библиотеки, драйверы, всё в `sys`). Для данных необязателен.
- Если хэша нет, при первой загрузке запоминаем его и предупреждаем при изменении (доверие при первом использовании).
- Заглушки по умолчанию только для чтения (Pastebin не умеет правку).
- Открытие: кеш, если есть; иначе скачать, проверить хэш, записать в кеш; без сети и без кеша ошибка "недоступно".

## `.rv` (запись восстановления)

Для критичного файла: упорядоченный список источников и хэш. Первый подошедший по хэшу побеждает; после восстановления указывается, что запустить. К буквам `.cloud` добавляется `L:` (локальный путь).

```
L: /cubeos/sys/recovery/kernel.bak
P: 12345gg
C: example.com/cc/kernel.lua
sha256=...
```

## `.cpk` (пакет)

Бинарный контейнер, как JAR: архив с метаданными.

Раскладка:
```
сигнатура "CPK" + версия формата
манифест (JSON5, не сжат: читается без распаковки)
таблица файлов: путь, смещение, размер хранимый/исходный, метод сжатия, CRC32
данные
хэш содержимого (поле под подпись зарезервировано)
```

- Установленные приложения **не распаковываются**: VFS монтирует `.cpk` как каталог только для чтения. Экономит место, обновление это замена файла, откат это возврат старого. Распаковка модулей при загрузке кешируется в памяти.
- Запуск `.cpk` как exe: двойной клик монтирует архив во временный каталог и стартует `entry`. Установка необязательна. Разрешения спрашиваются при запуске или запоминаются по хэшу.

### Манифест

```json5
{
  format: 1,
  id: "denmoth.snake",          // автор.имя, уникально
  name: "Змейка",
  version: "1.2.0",             // SemVer
  description: "Классическая змейка",
  author: "Denmoth", license: "MIT", homepage: "",
  kind: "app",                  // app | lib | driver | theme | font | lang | data | de | distro | os
  entry: "main.lua",
  icon: "icon.cimg",
  ui: "both",                   // window | text | both

  cubeos: { target: "2.0.0", min: "2.0.0", max: null },

  permissions: {
    need: ["fs.appdata", "gfx"],
    want: ["net.http"],
  },
  caps: {
    need: ["gfx"],
    want: ["gfx.pixel", "audio.pcm", "mod:advancedperipherals"],
    compat: ["mod:createbigcannons"],       // проверено, только информация
    conflicts: [],                          // ломается вместе с этим
  },
  platform: {
    distro: { supports: ["*"], unsupported: [] },
    de:     { supports: ["*"], unsupported: [] },
  },

  depends: { "cube.ui": ">=1.0 <2.0" },     // пакеты, SemVer-диапазоны (^, ~, >=, <)
  provides: [],
  install: { scope: "user", size: 18240 },  // user | global
  associations: [".snk"],
  autostart: false,
  build: "cubic 0.2.1",                     // справочно, ни на что не влияет
}
```

Версия Cubic не требуется: результат это обычный Lua.

### Совместимость с версией ОС

`target` версия ОС, под которую собрано; `min`/`max` границы. Если мажорная версия ОС не совпадает с мажорной `target`, ОС ниже `min` или выше `max`, приложение помечается "может не работать". Запуск возможен с предупреждением. Пока ОС 0.x, любая минорная версия может ломать совместимость (правило SemVer), сравнивается минор.

### Зависимости

Диапазоны SemVer в нотации npm. `need` и `want` для пакетов тоже возможны; `conflicts` блокирует или предупреждает.

## `.cbx` (обычный архив)

Тот же бинарный контейнер, без обязательного манифеста. Дерево каталогов с пустыми папками и временем изменения. Утилита: `cpk pack|unpack|list|add`, окно в файловом менеджере. Возможен пароль (потоковый шифр).

### Методы сжатия

| Метод | Описание | Применение |
|---|---|---|
| 0 | без сжатия | уже сжатое, мелочь |
| 1 | быстрый (LZ4-подобный) | код смонтированных `.cpk` |
| 2 | сильный (LZ77 + энтропийное кодирование) | `.cbx`, установщики, ресурсы |

Метод указывается на каждый файл, можно смешивать в одном `.cpk`. Скорость в реальном CC **(измерить)**.

## `.stp` (установщик)

Заглушка-загрузчик + сжатый payload (один или несколько `.cpk`, сильный метод) + декларативный сценарий установки (JSON5: куда что положить через `$`-пути, ассоциации, ярлыки, права, пре-/пост-скрипты, опции, лицензия) + запись для удаления.

- По умолчанию использует распаковщик ОС (компактнее).
- Флаг `--standalone` вшивает собственный распаковщик (для установки на чистый CraftOS, например самой CubeOS).
- Текстовые каналы (Pastebin): ASCII-кодирование Base85 (+25%) вместо Base64 (+33%).
- Установщик дистрибутива скачивает нужную версию ОС вместе с ним (см. [11-platform.md](11-platform.md)).

## `.cimg` (изображение)

- Только индексные режимы: палитра 16 или 256 цветов в RGB. Truecolor не нужен (в CC 16 слотов палитры); поле режима в заголовке оставляет место для RGB, если CC: Graphics окажется богаче **(проверить API)**.
- **Прозрачность:** одна позиция палитры "прозрачная" (1-бит); полупрозрачности нет.
- Упаковка: по 2 пикселя в байт, **RLE** (повторы с количеством), по желанию быстрый LZ сверху. Метод в заголовке.
- Кадры: спрайт-листы и анимация.
- Читаем `.nft` и `.nfp` из CC.

## `.vimg` (вектор)

Планируется позже. Компактные пути (линии, кривые, фигуры) с индексами палитры. Растеризуется один раз и кешируется растром нужного размера. Полезно для больших картинок и масштабирования интерфейса, на иконках 16-32 пикселя рисованный растр лучше.

## Эмодзи и иконки

- Цветные эмодзи это атласы `.cimg` 8x8 и 16x16, подключаются кодом `:smile:` и тегом `<emoji:smile>`. Кодовые точки Unicode сопоставляются тому же набору. В текстовом режиме запасной вариант ASCII (`:)`).
- Одноцветный шрифт иконок и символов в `.font` в частной области Unicode, красится цветом текста.

## `.font`

Заголовок, таблица диапазонов Unicode, растровые глифы 1 бит на пиксель (фиксированный или пропорциональный), метаданные (имя, размер, стиль, лицензия). Кернинг по желанию.

## `.lang`

Строки `ключ: текст`, комментарии `#`, плейсхолдеры `{name}`, формы множественного числа, цепочка запасных языков (ru, затем en).

### Теги

Стиль MiniMessage:
```
welcome: Привет, <green>{name}</green>! У тебя <bold>{count}</bold> сообщений.
warn: <#ff8800>Мало места</>: осталось {free}
```
- `<цвет>`, `<#rrggbb>`, `<bold>`, `<italic>`, `<underline>`, `</>` закрывает всё, `\<` экранирование.
- В текстовом режиме цвета приводятся к палитре терминала; неподдерживаемое отбрасывается.
- Базовые теги в `sys/cfg/tags.conf`; DE и дистрибутивы регистрируют свои с пространством имён (`<mide:glow>`). Неизвестный тег: содержимое без оформления.
- Нужно приложение-редактор переводов.

## `.conf` (JSON5)

Стандартный JSON5. Запись значения точечная (заменяется только текст значения, комментарии сохраняются). Дефолты и пользовательские переопределения хранятся раздельно.

## `.cuh`

Описания типов API для строгого режима Cubic: сигнатуры функций, типы значений, поля. Лежат в `sys/api` (необязательный SDK) и рядом с библиотеками.
