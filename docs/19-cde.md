## Шаг 1: как устроено

```
приложение (процесс ядра)          оконный менеджер cde.wm (процесс сессии, держит фокус ввода ядра)
  win = cde.app.open(sys, ctx, ..)   ── окно: общий объект в памяти ──>   список окон (z-порядок), фокус, мышь, клавиши
  рисует в win.canvas / win.cells                                         cde.compositor: обои + окна по изменённым местам
  win:present() ── cubeos_cde (sys.post) ──>  менеджер забирает изменённую область canvas
  win:wait_event() <── key, char, mouse_*, win_* (sys.post, координаты окна) ──
```

- **Окно это объект `cde.window`**, общий для приложения и менеджера (все процессы в одной Lua-машине, поэтому картинка не пересылается). Пиксельное окно: `win.canvas` (поверхность `cgl`). Текстовое: `win.cells` (`ui.cells`, цвета CC 0..15) рисуется шрифтом Monocraft 6x9 в тот же canvas при `win:present()`, курсор мигает, пока окно в фокусе.
- **Ввод.** Все события CC получает менеджер (фокус ядра у него). Сочетания он обрабатывает сам, остальное передаёт окну в фокусе (мышь окну под курсором) новым вызовом ядра `sys.post` в координатах окна; последний аргумент номер окна. Окно будит менеджер тем же `sys.post` событием `cubeos_cde` (потомок предку можно только `cubeos_*`).
- **Сборка кадра** (`cde.compositor`): список изменённых прямоугольников, близкие сливаются; для каждого ищется верхнее окно, которое закрывает его целиком (тогда нижние слои не рисуются), иначе обои; поверх окна снизу вверх: тень (затемнение таблицей `theme.dim_map`), заголовок, содержимое, рамка со скруглёнными углами. Потом `cgl` сравнивает кадр только в изменённой области. Один символ в текстовом окне пересобирает одну клетку (это проверяет тест).
- **Палитра одна на экран** (`cde.theme`): 0..15 цвета CC в тонах темы, 16..231 куб 6x6x6, 232..255 цвета интерфейса (обои, рамки, заголовки). Приложения берут цвета через `cde.app.rgb` и `cde.app.ramp` (ближайшие по всей палитре) или роли темы (`app.theme.WIN_BG`, `TITLE_TEXT`). Темы шага 1: `tokyo-night` (по умолчанию), `dark`, `light`; файлами их сделает cdk (шаг 2). Тёмных тонов в кубе мало (уровни 0, 95, 135...): на шаге 2 решить, отдавать ли часть палитры под плавные тёмные ступени.
- **Процессы приложений** запускает `wm:launch(program, {name}, args)`: дочерние процессы менеджера; обёртка ловит ошибку и закрывает окна упавшего приложения (`wm.exits`), раз в секунду менеджер сверяет окна со списком процессов (убитые снаружи).

## Шаг 2.1: темы файлами и вид окон (2026-10-16)

- **Тема это файл** `assets/themes/<имя>.theme` (JSON5, свои кладутся туда же или в папки `theme_dirs` менеджера; поля, которых нет в файле, берутся из встроенной Tokyo Night). Готовые: `tokyo-night` (по умолчанию: значки справа, градиент в заголовке, углы 2), `dark` (в духе KDE: «закрыть» в круге, стрелки, заголовок по центру, углы 3), `light` (в духе Mac: цветные кружки слева, порядок закрыть/свернуть/развернуть, по центру, углы 4), `nord` (кружки справа, без рамки, углы 3).
- **Поля:** `text` (16 цветов CC), `desk` (ступени обоев), `title_active` (цвет или список цветов: градиент слева направо), роли (`win_bg`, `title_inactive`, `title_text`, `title_dim`, `border_active`, `border_inactive`, `close`, `button_down`, `accent`, `preview`, `desk_line`, `desk_glow`, `btn_close`, `btn_min`, `btn_max`) и `window`: `buttons` (`left`/`right`), `order`, `style` (`win`, `mac`, `kde`), `radius` (0..4), `border` (true/false), `title_height`, `title_align` (`left`/`center`), `shadow` (0..3), `shadow_strength`.
- **Палитра** (`cde.theme`): 0..15 цвета CC темы, 16..215 куб, 216..223 обои, 224..231 градиент заголовка, 232..247 роли, 248..255 запас (анимации палитрой, шаг 2.5).
- **Заголовок** собирается в отдельную картинку и пересчитывается только при изменении (фокус, название, нажатая кнопка, размер, тема), поэтому градиент с узором Байера ничего не стоит при перерисовке. Скругление делается отсечением строк углов, там видно то, что под окном; тень повторяет скругление.
- **Смена темы на ходу:** `wm:set_theme(имя)` (пока сочетание Ctrl+Alt+T, потом «Настройки»): палитра (обои и всё, что нарисовано цветами темы, меняются без перерисовки), рамки по новой теме, размер содержимого окон сохраняется, окна получают `win_theme`.
- **F11:** полный экран без рамки (`state = "full"`), повторно обратно к прежнему состоянию; окна постоянного размера тоже можно.
- **Свой заголовок приложения:** `{decorations: false}` (рамки и заголовка менеджера нет, содержимое с края окна), `win:set_drag_areas([[x, y, w, h]])` за эти места окно таскают и разворачивают двойным кликом, `win:request("min" | "max" | "full" | "normal")` кнопки приложения; края для размера, тень и скругление остаются у менеджера. Пример: «Mini player» в демо.
- **Расстановка новых окон** как «умная» в KDE: из точек сетки берётся та, где окно меньше всего закрывает видимые окна, при равенстве ближе к центру.
- Тесты: `lib_cde_theme` (файлы тем, порядок и сторона кнопок, скругление, свой заголовок, F11, смена темы), `lib_cde_wm`, `lib_cde_session`.

## Шаг 2.2: масштаб, палитра, свои цвета приложений (2026-10-16)

- **Масштаб через логические пиксели.** Менеджер, окна, мышь и приложения работают в логическом экране (экран / масштаб); композитор собирает кадр в логической поверхности и увеличивает только изменённые места на настоящий экран (`blit` со `scale`). Поэтому любое приложение крупнее без своей работы. Масштаб `"auto"` (по умолчанию): `min(ширина / 420, высота / 240)` с округлением вниз, от 1 до 4 (экран компьютера 306x171 это 1x, монитор 984x729 это 2x с логическим экраном 492x364); число 1..4 задаёт масштаб (меньше, если логический экран вышел бы уже 200x110). Смена размера экрана на ходу (`term_resize`, `monitor_resize`: компьютер или монитор поменяли размер) пересчитывает масштаб, обои и окна (не влезающие уменьшаются и сдвигаются). Касание монитора (`monitor_touch`) работает как клик.
- **Сочетания:** Ctrl+Alt+= и Ctrl+Alt+- крупнее и мельче (сессия CDE), Ctrl+Alt+T тема. Выбор сохраняется в `$cfg/cde.conf` (`theme`, `scale`), при входе читается оттуда.
- **Палитра v2:** 16..31 серые (16 ступеней), 32..211 общие цвета: 12 оттенков x 3 насыщенности x 5 яркостей, в том числе тёмные тона (в кубе 6x6x6 их не было). Приложения берут ближайший цвет (`app.rgb`, `app.ramp`).
- **Свои места палитры:** `slots = win:alloc_colors(n)` (12 мест: 212..215 и 248..255), `win:set_colors([[номер, r, g, b], ...])` меняет их цвет без перерисовки пикселей (анимация палитрой для приложений и живых обоев); чужие номера пропускаются, смена темы их не трогает, места освобождаются вместе с окном.
- Тест `lib_cde_scale` (тёмные тона, авто 2x на мониторе, пиксели 2x2, мышь в логических пикселях, свои места палитры, смена темы их не трогает, монитор растянули до 4x и обратно 1x, освобождение мест); `lib_cde_session` проверяет запись темы в `cde.conf`.

## Шаг 2.3: ядро cdk и простые элементы (2026-10-16)

Код `lib/cdk/`. Приложение открывает окно с элементами: `ui = cdk.open(sys, ctx, {title, w, h})`, `ui:set_root(дерево)`, `ui:run()`. Витрина `cdk.gallery` (Ctrl+Alt+K в сессии и в демо), кадры `bash tools/cdk_shots.sh` → `build/ui_cdk_*.png`.

- **Дерево** (`cdk.widget`): у элемента прямоугольник, дети, `measure` (желаемый размер), `layout`, `draw`, `handle`; общие свойства `grow`, `width`, `height`, `min_w`, `min_h`, `max_w`, `visible`, `enabled`, `id`. Раскладки: `row`, `column` (gap, padding, align: start/center/end/stretch, justify: start/center/end/between), `card` (столбец или ряд с фоном элемента и скруглением), `grid(cols)`, `spacer`. Всё резиновое: окно растянули, сменили масштаб или тему, и элементы раскладываются заново.
- **Среда** (`cdk.ui`): после раскладки рисуется весь холст, дальше только элементы, вызвавшие `invalidate` (их прямоугольник заливается фоном родителя, фон родителя-карточки дорисовывается). Фокус: Tab и Shift+Tab по кругу, клик по элементу. Мышь: элемент под нажатием захватывает перетаскивание и отпускание, `click` приходит, если отпустили над тем же элементом. Таймеры `ui:after`, `ui:every` по часам ядра. Буквы второго языка (кириллица из Windows) переводятся по раскладке системы, как в терминале (D235). События окна: `win_resize` и `win_theme` раскладывают заново (тема: `style:rebuild`), `win_close` закрывает (можно `on_close`, вернувший false).
- **Вид** (`cdk.style`) из темы: роли палитры `ctrl_bg`, `ctrl_hi`, `accent_text`, `sel` (новые поля файлов тем), скругление (раздел `cdk: {radius, padding, gap}` в теме, иначе как у окон), полоска света сверху и тень снизу у плашек, кольцо фокуса акцентом.
- **Элементы** (`cdk.controls`, `cdk.input`): надпись (normal, title крупно с тенью, dim, accent, danger), кнопка (normal, primary, flat, danger, со значком; Enter и пробел), значок (`cdk.icons`, 23 значка 9x9 в два тона, `icons.register` свои), флажок, переключатель, ползунок (мышь, колесо, стрелки, Home/End, шаг), полоса загрузки (обычная и бегущая), разделитель, поле ввода по схеме D223 (курсор, Shift-выделение, Ctrl по словам, Ctrl+A/C/X/V/Z/Y, пароль, выделение мышью, прокрутка длинного текста, подсказка). Буфер обмена пока общий для окон cdk (`cdk.input.clipboard`); системный (служба `clipboard`) подключить вместе с панелью.
- Тест `lib_cdk`.

## Шаг 2.4: списки, вкладки, меню, диалоги (2026-10-16)

- **Слои поверх окна** (`cdk.ui`): `ui:open_layer(w, {x, y, center, modal, dismiss, on_close})`, `ui:close_layer(w)`. Фокус и Tab живут в верхнем слое; клик мимо закрывает слой с `dismiss` (меню), модальный слой (диалог) затемняет окно и не пускает к нему ввод; Esc закрывает верхний слой (у слоя может быть `on_escape`). Под слоем тень. Элемент окна, перерисованный под модальным слоем, снова затемняется, слои рисуются поверх.
- **`cdk.scroll(child, {height})`**: колесо, полоса справа (тянуть), PageUp/PageDown; частичная перерисовка элементов внутри отсекается по окну прокрутки.
- **`cdk.list_view({items: [{text, icon, detail, color}], on_select, on_activate, height})`**: рисуются только видимые строки; клик, стрелки, Home/End, PageUp/PageDown, двойной клик и Enter (`on_activate`), колесо, полоса; выбранная строка подсвечена, в фокусе акцентная метка слева.
- **`cdk.tabs({tabs: [{title, content}], index, on_change})`**: клик по заголовку, ←/→ в фокусе, Ctrl+Tab; активная вкладка с подчёркиванием акцентом.
- **`cdk.menu(ui, items, x, y)`**: пункты `{text, icon, shortcut, checked, disabled, on_select}` и `{separator: true}`; стрелки пропускают разделители и недоступные, Enter, нажать и отпустить мышью. **`cdk.dropdown({items, index, on_change})`**: кнопка со стрелкой, открывает меню под собой, ↑/↓ меняют выбор сразу.
- **`cdk.dialog(ui, {title, text, icon, buttons: [{text, variant, icon, value}], on_result})`**: модальный, текст переносится по словам, фокус на последней кнопке (Enter), Esc даёт `on_result(nil)`, после закрытия фокус возвращается. `cdk.message(ui, заголовок, текст)`.
- Витрина: вкладки Controls и Lists (файлы со значками, выпадающий список масштаба, меню, диалог удаления). Тест `lib_cdk_lists`.

## Шаг 2.5: анимации (2026-10-16)

- **Окна** (`cde.fx`): на время анимации окно заменяется «призраком» (снимок окна), который композитор рисует поверх всего с растяжением и проявлением узором Байера 4x4 (уровень 0..16). Появление: подъём на 8 пикселей и проявление (0,2 с); закрытие: опускание и растворение (0,16 с); свернуть: улетает к низу экрана по центру (потом кнопка на панели) и тает; вернуть обратно; развернуть, половинки, F11 и обратно: старый снимок растягивается в новый прямоугольник (0,17 с), приложение тем временем перерисовывается под новый размер. Окно, которое тянут мышью из развёрнутого состояния, возвращается без анимации. Во время анимации менеджер рисует кадр каждые 50 мс, в покое не тратит ничего.
- **Свечение рамки** при получении фокуса: цвет `border_active` вспыхивает и за 0,45 с возвращается, только сменой палитры.
- **Элементы cdk** (`ui:tween(цель, поле, значение, секунды, кривая)`): переключатель (ручка едет, дорожка перетекает в акцент узором Байера), флажок (отметка вырастает из середины с небольшим перескоком), подсветка строки списка плывёт, подчёркивание вкладки скользит, полоса загрузки догоняет значение, меню раскрывается вниз, диалог от середины.
- **Настройки** (`$cfg/cde.conf`, `animations`): `enabled`, `speed` (множитель: 2 вдвое быстрее), `windows`, `glow`, `widgets`. Ctrl+Alt+A включает и выключает всё (сохраняется). Выключенные анимации срабатывают сразу.
- GIF настоящих кадров: `bash tools/anim_shots.sh` → `build/ui_anim_windows.gif`, `build/ui_anim_widgets.gif`. Тест `lib_cde_fx`; в остальных тестах поведения анимации выключены (`animations: {enabled: false}`).

## Шаг 3.1: панель задач (2026-10-16)

Код `lib/cde/panel.cub` (`cde.panel`), значки переехали в `lib/cde/icons.cub` (`cdk.icons` их перепоказывает). Тест `lib_cde_panel`, кадры `bash tools/panel_shots.sh` → `build/ui_panel_*.png`.

- **Панель это слой композитора**, а не окно: готовая картинка `panel.surf` пересобирается, только когда поменялось то, что на ней видно (окна, названия, фокус, время, тема); композитор кладёт её поверх окон и под анимации. Включается настройкой `panel` менеджера (`cde.wm.new({panel: {...}})`; без неё панели нет, как в старых тестах); сессия включает её всегда (`$cfg/cde.conf`, `panel`: `position` `"bottom"`/`"top"`, `align` `"left"`/`"center"` где кнопки окон, `height`, `clock`).
- **Состав:** слева «Пуск» (кнопка с кубом; вызывает `wm.on_start`, как одиночный левый Alt; меню придёт в 3.2), кнопки окон по порядку открытия (значок окна `icon` из `cde.icons` или буква названия на цветной плашке, название; при тесноте только значки), справа часы (из `time.conf` системы: пояс, 12/24 часа, секунды) и узкая полоса у края «показать рабочий стол» (как Alt+D). Окно в фокусе: светлая кнопка и акцентная черта снизу, открытое: чёрточка, свёрнутое: тусклое без фона. `{taskbar: false}` в параметрах окна убирает его с панели.
- **Нажатия** срабатывают при отпускании над той же кнопкой (пока держат, кнопка тёмная): кнопка окна поднимает окно, возвращает свёрнутое, у окна в фокусе сворачивает его; средняя кнопка мыши закрывает окно; колесо над панелью листает окна; клик по пустому месту панели ничего не делает и не отнимает фокус.
- **Рабочая область** `wm.area` это экран без панели: сюда разворачиваются окна (`max`), встают половинки и рамка предпросмотра прилипания, новые окна расставляются «умно», заголовок перетаскиваемого окна не уходит под панель. Полный экран (F11) занимает весь экран и прячет панель. Смена положения панели на ходу (`wm:set_panel({position, align, height, clock})`) переставляет окна по новой области.
- **Сворачивание** летит в кнопку окна на панели (`fx:dock_rect`).
- **Сочетания:** Ctrl+Alt+P панель сверху или снизу, Ctrl+Alt+L кнопки окон слева или по центру (пока нет «Настроек»; выбор сохраняется).
- **Область уведомлений** расширяется списком `panel.tray` (`{key, w, draw(panel, s, x, y, w, h), click(panel, button)}`): сеть, звук, раскладка придут в 3.3.
- **Не проверено в игре:** вид на настоящем экране, время (`time.conf` читается из `/cubeos/sys/cfg`). Правый клик по кнопке (меню окна) не сделан.

## Шаг 3.2: «Пуск» с поиском (2026-10-16)

Код `lib/cde/apps.cub` (каталог и поиск), `lib/cde/startmenu.cub` (меню), сборка в `cde.session`. Тесты `lib_cde_start` (поиск, меню, клавиши, закрытие) и вставка в `lib_cde_session`; кадры `bash tools/panel_shots.sh` (`ui_panel_*_menu*.png`).

- **Меню это окно cdk без рамки** (`decorations: false`, `taskbar: false`) у кнопки «Пуск» (над панелью или под ней, если панель сверху): поле поиска, список, внизу пользователь и кнопка «Log out». Открывается кнопкой на панели, одиночным левым Alt и Ctrl+Space, тем же повторно закрывается; закрывается и при потере фокуса (клик по окну, рабочему столу, другой кнопке). Появляется с анимацией окон. Кнопка «Пуск» на панели тёмная, пока меню открыто (`panel.start_open`).
- **Ввод:** буквы сразу идут в поле поиска (любая раскладка, кириллица по раскладке системы), ↑ ↓ PgUp PgDn по списку, Enter запускает выбранное, Esc сначала стирает запрос, потом закрывает. Код Esc в CC это 256 (`keys.escape` нет).
- **Каталог** (`cde.apps`): запись `{id, name, icon, keywords, kind: "app" | "action", run(wm)}`; `reg:add`, `reg:provider(fn)` (записи заново при каждом поиске: темы, масштаб), `reg:search(запрос)`. Пустой запрос: только приложения, самые запускаемые выше (`reg:used`); команды (`kind: "action"`) видны только в поиске. Поиск без учёта регистра, все слова запроса должны найтись: название целиком, с начала, с начала слова, внутри, буквы по порядку; ключевые слова (в том числе русские и украинские) весят 0,6. Вес запусков ограничен, чтобы не заглушать совпадение.
- **Запуск** выполняется в процессе менеджера (`wm:defer(fn)`: новый вызов менеджера, из приложений нельзя менять тему и писать окнам напрямую), поэтому запись может сменить тему, масштаб, панель, запустить приложение, выйти из сессии.
- **Записи сессии:** Terminal, Widget gallery; команды: «Theme: <имя>» для каждой темы, «Scale: Auto/1x..4x», «Panel at the top/bottom», «Panel buttons in the center/left», «Animations: turn on/off», «Log out». Выбор темы, масштаба и панели сохраняется в `cde.conf`. Новые приложения (шаг 5) просто добавляют записи в каталог.
- **Не сделано:** закреплённые записи и «недавние» отдельным списком, категории, значки из файлов, поиск по файлам, блокировка в нижней строке (шаг 4), питание (выключить, перезагрузить) в нижней строке.

## Шаг 3.3: область уведомлений (2026-10-16)

Код `lib/cde/tray.cub` (`cde.tray`), подключается в `cde.session`. Тест `lib_cde_tray` (подставные службы audiod, netd, inputd), кадры `tools/panel_shots.sh` (`ui_panel_*_tray*.png`).

- **Значки** слева от часов (справа налево: раскладка, звук, сеть): раскладка это код второго языка клавиатуры (`RU`; акцентом, если раскладка переключается в CubeOS, тускло, если следует за Windows), звук (громкость; тускло и перечёркнуто при 0 или без службы), сеть (тускло: нет модема, обычный: есть модем, акцентом: есть сопряжённые компьютеры). Значки это `panel.tray` из шага 3.1.
- **Данные** собирает отдельный процесс «tray» раз в 3 секунды (`svc.rpc`: `audiod status`, `netd status`, `inputd get`) и передаёт менеджеру через `wm:defer`; менеджер сам ждать службы не может. Нет службы (компьютер без звука или сети): значок тусклый, окошко это говорит. Окошки меняют настройки сразу и обновляют значок (`tray:patch`).
- **Окошко** (клик по значку, повторный клик закрывает, потеря фокуса и Esc тоже): рамка без заголовка над панелью (под ней, если панель сверху), как меню «Пуск». Звук: ползунок громкости (настоящая громкость `audiod`), «Mute»/возврат прежней громкости, «Test» (нота), сколько динамиков. Сеть: имя компьютера, тип модема, список известных компьютеров (замок: сопряжён), «Scan». Раскладка: второй язык из `inputd`, «Follow Windows» или «Switch in CubeOS» (меняет только администратор, иначе ошибка службы видна в окошке).
- **Колесо** над значком звука меняет громкость на 5 (над остальной панелью листает окна).
- **Не сделано:** уведомления (`notifyd`) и значок с их числом, сопряжение и общие папки из окошка сети (команда `net`), питание и батарея. Значок раскладки показывает настройку системы, а не раскладку в конкретном окне (она у каждого окна своя).

## Мышь и клавиши (шаг 1)

| Действие | Как |
|---|---|
| Поднять окно, фокус | клик в любом месте окна |
| Переместить | тянуть заголовок; у верхнего края экрана рамка предпросмотра «на весь экран», у левого и правого «половинка», отпустить там |
| Развернуть, вернуть | двойной клик по заголовку, кнопка □, Alt+↑ / Alt+↓ |
| Половинки | Alt+Shift+← / → (повторно вернуть), перетаскивание к краю |
| Свернуть | кнопка _, Alt+↓ в обычном состоянии; вернуть Alt+←/→ |
| Размер | тянуть края и углы (полоса 2 пикселя), текстовое окно меняется целыми клетками |
| Предыдущее / следующее окно | Alt+← / Alt+→ (по порядку открытия) |
| Закрыть | кнопка ×, Ctrl+T (окно получает `win_close`), удержание Ctrl+T убивает приложение |
| Рабочий стол | Alt+D (повторно вернуть окна) |
| Полный экран | F11 (повторно вернуть) |
| Следующая тема | Ctrl+Alt+T (пока нет «Настроек») |
| Крупнее, мельче | Ctrl+Alt+=, Ctrl+Alt+- (масштаб 1x..4x, «auto» по размеру экрана) |
| Витрина cdk | Ctrl+Alt+K |
| Анимации вкл/выкл | Ctrl+Alt+A |
| Панель сверху / снизу, кнопки окон слева / по центру | Ctrl+Alt+P, Ctrl+Alt+L |
| «Пуск» с поиском | одиночный левый Alt, Ctrl+Space, кнопка на панели |
| «Пуск» | одиночное нажатие левого Alt вызывает `wm.on_start` (меню «Пуск», шаг 3.2) |
| Свои сочетания | `wm:hotkey("alt+enter", fn)` |

Развёрнутое или прилипшее окно, которое тянут за заголовок, возвращается к прежнему размеру под мышью. Окно с `resizable: false` не разворачивается и не прилипает. Наведения мыши в CC нет (только нажатия и перетаскивание), поэтому кнопки подсвечиваются только при нажатии.

## API окна для приложений

```cubic
import cde
def main(sys, ctx):                                     # ctx от wm:launch: ctx.wm, ctx.args
    win = cde.app.open(sys, ctx, {title: "Hello", kind: "text", cols: 30, rows: 8})
    win:text(1, 1, "Привет", 0, 15)                      # цвета CC: 0 белый ... 15 чёрный
    win:present()
    while true:
        ev = table.pack(win:wait_event(0.5))            # nil по таймауту
        if ev[1] == "win_close":
            break
    win:close()
```

События окна: `key(код, held, id)`, `key_up(код, id)`, `char(символ, id)`, `paste(текст, id)`, `mouse_click/mouse_drag/mouse_up(кнопка, x, y, id)`, `mouse_scroll(направление, x, y, id)` (пиксельное окно: пиксели содержимого с нуля; текстовое: клетки с единицы, как в терминале CC), `win_resize(ширина, высота, id)` (`win.canvas` уже новая поверхность, нарисовать заново), `win_close(id)`, `win_focus(id)`, `win_blur(id)`. Параметры окна: `title`, `kind` (`pixel`/`text`), `w`, `h` или `cols`, `rows`, `x`, `y` (иначе лесенкой от центра), `resizable`, `min_w`/`min_h` или `min_cols`/`min_rows`, `bg`.
