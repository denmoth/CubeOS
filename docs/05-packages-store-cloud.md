Полное описание (транзакции, расчёт места, источники и сторонняя установка, команды): [spec/package-manager.md](spec/package-manager.md). Кратко ниже.

## Абстракция "хранилище"

Единый интерфейс с подключаемыми бэкендами. Выбор в настройках.

| Бэкенд | Плюсы | Минусы |
|---|---|---|
| Pastebin | Работает между серверами, ничего хостить не надо | см. ниже |
| GitHub Gist | Стабильный ID, правка через API с токеном, история | нужен токен |
| GitHub (репозиторий) | Каталог магазина, версии, нормальный размер | нужен внешний ресурс, `http` в CC включён |
| Свои компьютеры (rednet) | Приватно, без лимитов | Только в пределах одного мира/сервера, компьютер должен быть включён |

Межсерверная связь вне приоритета.

## Pastebin

- Чтение `https://pastebin.com/raw/<id>` ключа не требует.
- Запись через API требует `api_dev_key` **(проверить)**. Стоковая `pastebin put` в CC использует общий зашитый ключ. Планируем: каждый игрок вписывает свой бесплатный ключ в настройках.
- Логин (`api_login`) по имени и паролю даёт пользовательский ключ. Пароль не храним, только ключ.
- Через API можно создавать, листать свои записи, удалять **(проверить)**. **Редактировать запись через API нельзя**, по моим данным **(проверить)**. В веб-интерфейсе правка записей с аккаунта возможна. "Правка" из ОС это создать новую и удалить старую; приложение ведёт индекс "имя -> текущий ID", чтобы записи не терялись.
- Лимиты по размеру и частоте **(проверить)**. Закладываем повторные попытки и кеш.
- Файлы без аккаунта (гостевые) лежат под случайными ID, поэтому приватность умеренная. Шифрование по паролю или ключу необязательно.

## Роли Pastebin и Gist

Gist не заменяет Pastebin, они дополняют друг друга:

| | Pastebin | Gist |
|---|---|---|
| Запись без аккаунта | Да (нужен ключ разработчика) | Нет, нужен аккаунт GitHub и токен |
| Правка записи через API | Нет **(проверить)** | Да, ID не меняется |
| История версий | Нет | Да |
| Подходит для | Быстрый обмен, раздача, гостевые файлы | Синхронизация настроек и сохранений |

Вывод: Pastebin остаётся основой для обмена, Gist подключается там, где нужна правка. Оба доступны через общий интерфейс хранилища.

## Gist

Дополнительный бэкенд, когда нужна правка. Чтение через `gist.githubusercontent.com/.../raw` может кешироваться CDN с задержкой после правки **(проверить)**. `http.request` в CC умеет PATCH/PUT/DELETE **(проверить)**. Нужен личный токен. Токен хранится в защищённом хранилище ОС, не в открытом конфиге.

## Rednet-облако

Сервер на отдельном компьютере с модемом: протокол запросов (get/put/list/delete), права по паролю, шифрование опционально.

## Магазин

- Каталог это репозиторий на GitHub: отдельные папки на приложение, добавление через PR.
- Индекс `index.json5` (список приложений, версии, хэши, разрешения).
- Любой желающий может подключить свой каталог по ссылке (GitHub, другой хостинг, Pastebin).
- Загрузка из Майнкрафта: решено делать сразу, через Worker, открывающий PR (D263, docs/packages/06-cobble.md).
- Безопасность: показ разрешений, хэш из индекса, песочница. Подписи (ed25519) слишком медленны на чистом Lua, на старте не нужны.

## Продвинутый pastebin (утилита)

Замена стоковой `pastebin`:
- вход в аккаунт, список записей, `get/put/delete`;
- индекс ID;
- шифрование опционально.
Редактирование записи через API **(проверить)**; если нельзя, то "создать новую и удалить старую".
