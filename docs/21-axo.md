# 21. Axo (Axolotl): файловый менеджер CDE (с 2026-10-17)

Решения владельца (D260). Похож по духу на Dolphin (KDE), но свой; Windows Проводник владелец не любит. Подшаги ниже отмечать по мере готовности.

## Имя и вид в системе

- В интерфейсе **Axo** (кнопка панели, заголовок окна «Axo — <папка>», «Пуск»), полное имя **Axolotl** в «О программе» и подписи «Пуска» («Axo · Axolotl file manager»). Команды `axo [путь]` и синоним `axolotl`. Код `lib/apps/axo/`, настройки `$cfg/axo.conf`.
- Значок: узнаваемый розовый пиксельный аксолотль (жабры-«веточки» по бокам головы, улыбка, глазки), 9x9 для панели и меню и 32x32 для «О программе» и пустой папки («Тут пусто»). Поиск в «Пуске»: axo, axolotl, files, explorer, файлы, проводник, аксолотль.

## Раскладка

- Слева панель мест (Домой, Рабочий стол, Загрузки, Корзина, Сеть, диски, закладки), сверху путь, в центре таблица; панель сведений справа выключена по умолчанию. Всё переключается в настройках.
- Путь: если у папки есть алиас (`$home`, `$cfg`, свои), показывается алиас, потом кружок и полный путь: `$games ◦ /cubeos/users/denmoth/home/games` (длинный путь сокращается в середине только при показе). Клик по части пути переходит туда, клик по пустому месту делает путь полем для ввода.
- Вкладки: Ctrl+N новая, Ctrl+←/→ (и правый Alt+←/→) между вкладками; анимации вкладок выключаются, есть «минимальный режим» (без анимаций и украшений).
- Разделение на две панели F3 (как split view в Dolphin).
- Панель инструментов: значки без подписей, подписи всплывающими подсказками. В CC нет событий наведения мыши, поэтому подсказка появляется при удержании кнопки мыши на значке (отпустил на нём: действие, увёл: отмена) и при фокусе с клавиатуры.

## Файлы и действия

- Список: таблица «Имя, Размер, Изменён», сортировка кликом по заголовку, значки по типу (папка, текст, Lua, Cubic, картинка, музыка .dfpwm, архив, общая папка, расширитель). Миниатюр картинок нет (разрешение не позволяет).
- Двойной клик открывает, одиночный выделяет; Ctrl+клик и Shift+клик выделяют несколько.
- Скрытые (с точки и системные) скрыты, переключатель как в Проводнике (Ctrl+H); показанные скрытые идут в конце списка и выглядят полупрозрачными (тусклее).
- Удаление: Del в корзину и Shift+Del навсегда, оба спрашивают по умолчанию (вопрос отключается в настройках).
- Копирование и перемещение: прогресс полоской у края окна Axo, а не отдельным окном; если операций несколько, полоска сворачивается и разворачивается. Совпадение имён: заменить, пропустить, переименовать, «для всех».
- Перетаскивание мышью внутри окна, между окнами и вкладками, на места слева; Ctrl копирует.
- Поиск по именам по мере набора (текущая папка и вложенные).
- Пробел: быстрый просмотр (превью текста и картинки) прямо в Axo.

## Ассоциации

- Общий файл `/cubeos/sys/cfg/assoc.conf` и личный `$cfg/assoc.conf`, личный главнее. `.lua` по умолчанию открывается в cubed, запуск через меню.
- В контекстном меню всегда «Открыть с помощью…» и «Запустить» (для запускаемых файлов).
- Неизвестный тип: окно выбора приложения с галочкой «Всегда открывать так».
- Второе приложение: Ctrl+двойной клик (и Ctrl+Enter) открывает файл вторым приложением ассоциации (пример владельца: первое редактор, второе запуск). То же работает для файлов на рабочем столе и закладок в «Пуске».

## Сеть, права, свойства

- Раздел «Сеть» в местах: сопряжённые компьютеры и их общие папки, подключение одним кликом, «Поделиться» в меню своей папки.
- Права показываются в сведениях; меняются в окне свойств с подтверждением администратора (окно в духе UAC, свой системный диалог входа на sudo).

## Расширитель хранилища (делается вместе с Axo, отдельным подшагом)

- Расширителем может быть что угодно: другой компьютер по CubeNet, дискета, диск в дисководе.
- Подключается двумя способами: как отдельный диск (место в «Сети»/дисках) или прямо в существующую папку (продолжение папки).
- Расширитель сам хранит, к чему он прицеплен (метка на нём): при монтаже сам встаёт на свои папки, при демонтаже забирает свои файлы с собой.
- Новые файлы пишутся на расширитель, если на нём есть место (по умолчанию); приоритет настраивается у каждого.
- Совпадение имён: свой диск главнее, файл расширителя показывается рядом с пометкой.
- Расширитель отключён: его файлы остаются видны серыми с пометкой «нет связи» (это тоже выключается).
- Системные папки (ядро, `/cubeos/sys`, загрузчик) на расширитель не попадают никогда; приложение может лежать на расширителе только целиком, части одного приложения не разделяются.

## Связанное (отдельными шагами потом)

- **Pixel**: просмотрщик картинок; в меню «Сделать обоями», «Обоями блокировки», «Аватаром».
- **Рабочий стол с файлами** в стиле KDE (значки включаются и выключаются, выделение рамкой, папка `~/Desktop`).
- **Док как на Mac** (вариант панели).
- **Just**: поиск по системе как Spotlight (быстрый, красивый, превью на пробел).
- **«Пуск» доработать** (закладки, недавние, второе приложение через Ctrl).

Клавиши Ctrl+C, Ctrl+X (вырезанные тусклые), Ctrl+V, F2 (выделено имя без расширения), Ctrl+Shift+N, Del и Shift+Del с вопросом (`confirm_trash`, `confirm_delete` в axo.conf), правая кнопка: меню строки или пустого места. Перетаскивание на папку в таблице, место слева, вкладку и в другое окно Axo; Ctrl копирует. Работа идёт кусочками по таймеру окна (25 мс за раз), окно не замирает.

Неизвестный тип и «Open with...»: окно выбора с галочкой «Always open .ext files this way». 4. ✅ (2026-10-17) Быстрый просмотр на пробел, панель сведений, F3 разделение, поиск, настройки Axo (минимальный режим).
   Пробел: окно быстрого просмотра (текст первых 4 КБ, PgUp/PgDn; картинка .cimg вписывается в окно; папка списком; двоичные файлы не показываются), ↑↓ листают файлы прямо в нём, пробел и Esc закрывают. Ctrl+I панель сведений справа (значок крупно или превью картинки, имя, тип, размер, дата, «скрытый», «только чтение»; для нескольких: число и размер), F9 панель мест. F3 две панели: у правой своя папка и история (вкладки относятся к левой), активная та, по которой кликнули или куда перешёл фокус, путь, заголовок и кнопки показывают активную; перетаскивание между панелями. Ctrl+F поиск по именам в папке и вложенных (без учёта регистра, кириллица тоже), обход кусками по 15 мс, результаты с относительным путём появляются сразу, Esc возвращает папку. «Settings...» в меню: панели, скрытые, вопросы перед удалением, минимальный режим (без анимаций). В узкой таблице столбцы «Размер» и «Дата» прячутся, чтобы имя оставалось видно; Ctrl+стрелки таблица больше не забирает.
5. ✅ (2026-10-17) Сеть в местах, «Поделиться», окно свойств с правами и подтверждением администратора.
   Место «Network» (`network:`): компьютеры из `netd peers` (сопряжённые первыми), у сопряжённого его общие папки (`remote_shares`), Enter по папке: если подключена, открывает её, иначе подключает (`netd mount`) и открывает. В меню папки «Share on the network...» (имя, «только чтение») и «Stop sharing». Ctrl+P и пункт меню «Properties»: вид, место, размер (у папки считается не дольше 0,3 с), дата, права словами, действующее правило и кто что может, флаги; «Change access...» редактирует, кто что может (r w x l, добавить пользователя или роль), и сохраняет своё правило через `permd set_access` (`/cubeos/sys/cfg/access.conf`, грузится при загрузке поверх стандартных, системные места менять нельзя). Окно подтверждения администратора (в духе UAC): если служба отказала «нужен администратор», Axo спрашивает имя (если сам пользователь не администратор) и пароль и повторяет запрос с ними; так умеют `netd` (share, unshare, mount, unmount, ...) и `permd set_access`. Тест `lib_svc_permd`.
6. ✅ (2026-10-18) Расширитель хранилища (CFS: слоёные папки, метка на расширителе, приоритет записи, запреты).
   6.1 `cfs.extend`: слоёная папка из двух провайдеров (свой диск и расширитель), монтируется поверх существующей папки (`extend.over`). Список из обоих слоёв, одинаковые папки сливаются, при совпадении имён свой файл главнее, файл расширителя виден рядом как «name (label).ext». Файл читается и меняется там, где лежит (временные файлы атомарной замены ядра живут на слое своего файла). Новое по приоритету: «extender» (по умолчанию, если есть место с запасом `reserve`) или «local» (на расширитель, только когда своё место кончилось); внутри «неделимой» папки (приложение) туда, где она сама. Расширитель переполнился или пропал во время записи нового файла: файл ложится на свой диск, недописанный кусок удаляется (часть приложения: ошибка, не разъезжается). Не на связи: его файлы видны из сохранённого списка с `offline`, читать и менять нельзя. У записей `stat` и `list` поля `layer` ("local", "ext", "both"), `label`, `offline`. Тест `lib_cfs_extend`.
   6.2 `cfs.extlabel`: метка `.cubeos-extender` в корне устройства (json5: id, имя, точки подключения по компьютерам: путь, режим «folder» или «disk», приоритет). Метка в списках не видна и через файловую систему не меняется. `attach`/`detach` подключают по точкам (снимается только своё; занятое место, пропавшая папка, отказ проверки пропускаются с причиной). Тест `lib_cfs_extlabel`.
   6.3 Служба `extd` (`sys/services/extd.conf`): расширитель это любое смонтированное хранилище с меткой в `/cubeos/drives` (дискеты, devd) или `/cubeos/net` (общие папки, netd). Раз в 2 с смотрит подключённое: новое подключает по точкам из метки и своего списка `/cubeos/sys/cfg/extenders.conf` (там же сохранённые списки файлов для офлайна); пропавшее: папки остаются, файлы серые, «диск» снимается; вернувшееся (даже в другом дисководе) снова на связи. Защиты: корень, `/cubeos`, системные места, `/cubeos/drives`, `/cubeos/net` не расширяются; папку приложения и её части нельзя, папку приложений целиком можно (каждое приложение на одном слое); расширитель внутри расширителя нельзя; «диск» только в `/cubeos/mnt`. Запросы list, sources, make, add_point, remove_point, forget, rescan; менять может администратор (или имя и пароль администратора, UAC). Тест `lib_svc_extd`, служба поднимается в `lib_boot_system`.
   6.4 Axo: точка в углу значка у файлов расширителя (выключается в настройках «Mark files on extenders»), серые строки и «away» вместо даты, пока его нет; в сведениях «On cube-2» / «Also on cube-2». У папки «Extend with...» (расширитель на связи или устройство без метки: тогда имя и `make`; «New files stay here while there is room» даёт приоритет local) и «Detach» у расширенной папки (файлы расширителя уходят с ним). Окно «Extenders...» (меню, Ctrl+E): расширители, их точки, место, «away»; Open, As a disk (`/cubeos/mnt/<имя>`), Detach. Снимки `tools/axo_shots.sh` (12–15).
   6.5 Крайние случаи в тестах: переполнение посреди записи, обрыв посреди копирования (ничего не теряется), часть приложения при обрыве, совпадение имён, целое приложение.
