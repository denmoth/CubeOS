# 21. Axo (Axolotl): файловый менеджер CDE (с 2026-10-17)

Решения владельца (D260). Похож по духу на Dolphin (KDE), но свой; Windows Проводник владелец не любит. Подшаги ниже отмечать по мере готовности.

## Имя и вид в системе

- В интерфейсе **Axo** (кнопка панели, заголовок окна «Axo — <папка>», «Пуск»), полное имя **Axolotl** в «О программе» и подписи «Пуска» («Axo · Axolotl file manager»). Команды `axo [путь]` и синоним `axolotl`. Код `lib/apps/axo/`, настройки `$cfg/axo.conf`.
- Значок: узнаваемый розовый пиксельный аксолотль (жабры-«веточки» по бокам головы, улыбка, глазки), 9x9 для панели и меню и 32x32 для «О программе» и пустой папки («Тут пусто»). Поиск в «Пуске»: axo, axolotl, files, explorer, файлы, проводник, аксолотль.

## Раскладка

- Слева панель мест (Домой, Рабочий стол, Загрузки, Корзина, Сеть, диски, закладки), сверху путь, в центре таблица; панель сведений справа выключена по умолчанию. Всё переключается в настройках.
- Путь: если у папки есть алиас (`$home`, `$cfg`, свои), показывается алиас, потом кружок и полный путь: `$games ◦ /cubeos/users/denmoth/home/games` (длинный путь сокращается в середине только при показе). Клик по части пути переходит туда, клик по пустому месту делает путь полем для ввода.
- Вкладки: Ctrl+N новая, Ctrl+←/→ (и правый Alt+←/→) между вкладками; анимации вкладок выключаются, есть «минимальный режим» (без анимаций и украшений).
- Разделение на две панели F3 (как split view в Dolphin).
- Панель инструментов: значки без подписей, подписи всплывающими подсказками. В CC нет событий наведения мыши, поэтому подсказка появляется при удержании кнопки мыши на значке (отпустил на нём: действие, увёл: отмена) и при фокусе с клавиатуры.

## Файлы и действия

- Список: таблица «Имя, Размер, Изменён», сортировка кликом по заголовку, значки по типу (папка, текст, Lua, Cubic, картинка, музыка .dfpwm, архив, общая папка, расширитель). Миниатюр картинок нет (разрешение не позволяет).
- Двойной клик открывает, одиночный выделяет; Ctrl+клик и Shift+клик выделяют несколько.
- Скрытые (с точки и системные) скрыты, переключатель как в Проводнике (Ctrl+H); показанные скрытые идут в конце списка и выглядят полупрозрачными (тусклее).
- Удаление: Del в корзину и Shift+Del навсегда, оба спрашивают по умолчанию (вопрос отключается в настройках).
- Копирование и перемещение: прогресс полоской у края окна Axo, а не отдельным окном; если операций несколько, полоска сворачивается и разворачивается. Совпадение имён: заменить, пропустить, переименовать, «для всех».
- Перетаскивание мышью внутри окна, между окнами и вкладками, на места слева; Ctrl копирует.
- Поиск по именам по мере набора (текущая папка и вложенные).
- Пробел: быстрый просмотр (превью текста и картинки) прямо в Axo.

## Ассоциации

- Общий файл `/cubeos/sys/cfg/assoc.conf` и личный `$cfg/assoc.conf`, личный главнее. `.lua` по умолчанию открывается в cubed, запуск через меню.
- В контекстном меню всегда «Открыть с помощью…» и «Запустить» (для запускаемых файлов).
- Неизвестный тип: окно выбора приложения с галочкой «Всегда открывать так».
- Второе приложение: Ctrl+двойной клик (и Ctrl+Enter) открывает файл вторым приложением ассоциации (пример владельца: первое редактор, второе запуск). То же работает для файлов на рабочем столе и закладок в «Пуске».

## Сеть, права, свойства

- Раздел «Сеть» в местах: сопряжённые компьютеры и их общие папки, подключение одним кликом, «Поделиться» в меню своей папки.
- Права показываются в сведениях; меняются в окне свойств с подтверждением администратора (окно в духе UAC, свой системный диалог входа на sudo).

## Расширитель хранилища (делается вместе с Axo, отдельным подшагом)

- Расширителем может быть что угодно: другой компьютер по CubeNet, дискета, диск в дисководе.
- Подключается двумя способами: как отдельный диск (место в «Сети»/дисках) или прямо в существующую папку (продолжение папки).
- Расширитель сам хранит, к чему он прицеплен (метка на нём): при монтаже сам встаёт на свои папки, при демонтаже забирает свои файлы с собой.
- Новые файлы пишутся на расширитель, если на нём есть место (по умолчанию); приоритет настраивается у каждого.
- Совпадение имён: свой диск главнее, файл расширителя показывается рядом с пометкой.
- Расширитель отключён: его файлы остаются видны серыми с пометкой «нет связи» (это тоже выключается).
- Системные папки (ядро, `/cubeos/sys`, загрузчик) на расширитель не попадают никогда; приложение может лежать на расширителе только целиком, части одного приложения не разделяются.

## Связанное (отдельными шагами потом)

- **Pixel**: просмотрщик картинок; в меню «Сделать обоями», «Обоями блокировки», «Аватаром».
- **Рабочий стол с файлами** в стиле KDE (значки включаются и выключаются, выделение рамкой, папка `~/Desktop`).
- **Док как на Mac** (вариант панели).
- **Just**: поиск по системе как Spotlight (быстрый, красивый, превью на пробел).
- **«Пуск» доработать** (закладки, недавние, второе приложение через Ctrl).
