# Шрифты CubeOS: формат `.font` и набор

Код: `lib/font.cub` (чтение, текст), `lib/pixelbuf.cub` (буфер пикселей), сборка `tools/build_font.py`. Решения D134–D138 в [08-decisions-log.md](../08-decisions-log.md).

## Набор шрифтов

| Шрифт | Клетка | Глифов | Размер файла | Назначение |
|---|---|---|---|---|
| `cube-5x8` | 5×8 пикселей (в клетке терминала CC:Graphics 6×9) | 344 | около 3 КБ | основной, столько же колонок и строк, как у родного терминала (51×19) |
| `cube-8x16` | 8×16 | 637 | около 10,5 КБ | крупный, читаемее, меньше колонок |

Оба вместе меньше 20 КБ (требование D134), после сжатия `compress` ещё меньше.

Покрытие:
- **cube-5x8:** Basic Latin, Latin-1, кириллица (русская А–Я а–я Ё ё, украинская Є є І і Ї ї Ґ ґ), рамки (одинарные, двойные, скруглённые углы), блоки и тени, стрелки, галочки, часть математических и денежных знаков, заменитель U+FFFD.
- **cube-8x16:** Basic Latin, Latin-1, Latin Extended-A, греческий, кириллица (русская и украинская полностью), общая пунктуация, стрелки, математика, рамки, блоки, геометрические фигуры.

Происхождение: за основу взят шрифт Spleen (Frederic Cambus, лицензия BSD-2-Clause, текст в `assets/fonts/CREDITS`). Латиница и часть знаков из Spleen. Кириллица `cube-5x8` (у Spleen 5×8 кириллицы нет) нарисована для CubeOS вручную в стиле Spleen (`assets/fonts/src/cyrillic-5x8.txt`); украинские Є є для `cube-8x16` достроены из С с. Рамки, блоки и стрелки для 5×8 строятся скриптом.

## Формат `.font` (CFN1)

Все числа с младшего байта (little-endian), кроме строк глифов.

| Поле | Размер | Описание |
|---|---|---|
| магия | 4 | `CFN1` |
| ширина | 1 | ширина клетки в пикселях |
| высота | 1 | высота клетки в строках |
| ascent | 1 | строк выше базовой линии |
| флаги | 1 | 0 (резерв: пропорциональный шрифт) |
| число диапазонов | 2 | N |
| диапазоны | N раз | varint начало, varint длина (подряд идущие кодовые точки Unicode) |
| глифы | подряд | по порядку диапазонов; каждый глиф `высота × ceil(ширина/8)` байт; старший бит самого левого пикселя |
| метаданные | 2 + M | длина M и текст `ключ=значение;...` (имя, происхождение, лицензия) |

varint: по 7 бит, старший бит байта означает продолжение, младшие разряды первыми.

## Библиотека

```cubic
import font
import pixelbuf

f = font.from_file("/repo/assets/fonts/cube-5x8.font")
f:can_render("Привіт")             # true
buf = pixelbuf.new(60, 8)
f:draw(buf, 0, 0, "Привет", 1)     # рисует в буфер, цвет 1
```

- Моноширинный; текст UTF-8; нет глифа: заменитель U+FFFD (или `?`).
- Буфер выдаёт список строк цветов (`buf:rows()`) для `term.drawPixels` CC:Graphics.

## Правило без CC:Graphics

Родной терминал CC не рисует кириллицу, а транслитерация читается хуже английского (D135). Поэтому без CC:Graphics интерфейс показывает английские строки (`ru` и `uk` переводы работают только при пиксельном рисовании). Режим 2×3 субпикселей (символы 128–159) годится для картинок и игр, но не для текста.

## Пересборка

```
curl -sSL -o build/fonts-src/spleen/spleen-5x8.bdf https://raw.githubusercontent.com/fcambus/spleen/master/spleen-5x8.bdf
curl -sSL -o build/fonts-src/spleen/spleen-8x16.bdf https://raw.githubusercontent.com/fcambus/spleen/master/spleen-8x16.bdf
python -I tools/build_font.py
```

`tools/bdf_inspect.py файл.bdf` показывает покрытие символов в BDF.
