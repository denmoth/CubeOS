# Шрифты CubeOS: формат `.font` и набор

Код: `lib/font.cub` (чтение, текст), `lib/pixelbuf.cub` (буфер пикселей), сборка `tools/build_font.py`. Решения D134–D138 в [08-decisions-log.md](../08-decisions-log.md).

## Набор шрифтов

| Шрифт | Клетка | Глифов | В файле | Назначение |
|---|---|---|---|---|
| `cube-6x9` | 6×9 пикселей, ровно клетка родного терминала CC | 802 | около 3,1 КБ | основной: 51×19 колонок и строк, как у CC |
| `cube-5x7` | 5×7 | 866 | около 2,8 КБ | компактный: на том же экране около 61×24 |
| `cube-8x16` | 8×16 | 638 | около 2,9 КБ | крупный, читаемее, меньше колонок |

Файлы хранятся как блоки сжатия (`lib/compress`, метод deflate), `font.from_file` разворачивает их сам. Все три вместе около 8,8 КБ при лимите 20 (D134).

Покрытие: Basic Latin, Latin-1, Latin Extended-A, греческий, кириллица (русская и украинская полностью, заглавные и строчные, Ё ё Є є І і Ї ї Ґ ґ), пунктуация, валюты, стрелки, математика, рамки, блоки, фигуры, заменитель U+FFFD.

Происхождение (D147): `cube-6x9` и `cube-5x7` это шрифты X11 «misc-fixed» из коллекции Маркуса Куна (общественное достояние), в которых кириллица нарисована профессионально; `cube-8x16` это Spleen (BSD-2-Clause) с достроенными Є є. Тексты лицензий в `assets/fonts/CREDITS`. Первая версия на Spleen 5x8 была отвергнута: у неё нет кириллицы, акцентированные буквы в файле пустые, а сама буква мельче родной (4×6 в клетке 5×8 против 5×7 в клетке 6×9 у CC).

## Личный шрифт Minecraft (не распространяется)

Шрифт Minecraft принадлежит Mojang, поэтому в репозиторий и в образ ОС он **не входит** (D149). Для своей машины есть инструмент `tools/import_mc_font.py`: он читает `client.jar` вашей установленной игры, переводит растровые глифы Minecraft в моноширинную клетку 6×9 (узкие центрируются, шире 6 пикселей сжимаются слиянием похожих столбцов), достраивает недостающие буквы (Ё ё Є є Ї ї Ґ ґ), остальные символы берёт из общедоступного `cube-6x9` и пишет `assets/private/cube-mc-6x9.font`. Папка `assets/private/` в `.gitignore`, файл нельзя публиковать и раздавать. Оболочка использует его, если файл есть, иначе стандартный `cube-6x9`.

## Формат `.font` (CFN1)

Все числа с младшего байта (little-endian), кроме строк глифов.

| Поле | Размер | Описание |
|---|---|---|
| магия | 4 | `CFN1` |
| ширина | 1 | ширина клетки в пикселях |
| высота | 1 | высота клетки в строках |
| ascent | 1 | строк выше базовой линии |
| флаги | 1 | 0 (резерв: пропорциональный шрифт) |
| число диапазонов | 2 | N |
| диапазоны | N раз | varint начало, varint длина (подряд идущие кодовые точки Unicode) |
| глифы | подряд | по порядку диапазонов; каждый глиф `высота × ceil(ширина/8)` байт; старший бит самого левого пикселя |
| метаданные | 2 + M | длина M и текст `ключ=значение;...` (имя, происхождение, лицензия) |

varint: по 7 бит, старший бит байта означает продолжение, младшие разряды первыми.

## Библиотека

```cubic
import font
import pixelbuf

f = font.from_file("/repo/assets/fonts/cube-6x9.font")
f:can_render("Привіт")             # true
buf = pixelbuf.new(60, 8)
f:draw(buf, 0, 0, "Привет", 1)     # рисует в буфер, цвет 1
```

- Моноширинный; текст UTF-8; нет глифа: заменитель U+FFFD (или `?`).
- Буфер выдаёт список строк цветов (`buf:rows()`) для `term.drawPixels` CC:Graphics.

## Правило без CC:Graphics

Родной терминал CC не рисует кириллицу, а транслитерация читается хуже английского (D135). Поэтому без CC:Graphics интерфейс показывает английские строки (`ru` и `uk` переводы работают только при пиксельном рисовании). Режим 2×3 субпикселей (символы 128–159) годится для картинок и игр, но не для текста.

## Пересборка

```
# Spleen (крупный шрифт)
curl -sSL -o build/fonts-src/spleen/spleen-8x16.bdf https://raw.githubusercontent.com/fcambus/spleen/master/spleen-8x16.bdf
curl -sSL -o build/fonts-src/spleen/LICENSE https://raw.githubusercontent.com/fcambus/spleen/master/LICENSE
# коллекция X11 (основной и компактный): скачать https://www.cl.cam.ac.uk/~mgk25/download/ucs-fonts.tar.gz
# и распаковать 5x7.bdf и 6x9.bdf в build/fonts-src/ucs/
python -I tools/build_font.py
```

`tools/bdf_inspect.py файл.bdf` показывает покрытие символов в BDF, `tools/bdf_dump.py файл.bdf 0x41 0x416` рисует глифы.
