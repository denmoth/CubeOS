# UI: библиотека текстового интерфейса (TUI)

Код: `lib/ui/`. Тесты: `tests/cases/lib_ui_*.cub`. Демонстрация: `examples/ui_demo.cub`, запуск `game/ui_demo.lua`. Решения D174–D182 в [08-decisions-log.md](../08-decisions-log.md).

Это TUI в стиле «страниц» из старого CubeUI (`cui 0.2.0` и `cubeui` на Pastebin): страница на весь экран с шапкой, разделителем, содержимым и подвалом с подсказками клавиш, полоса выбора цветом темы, диалоги и уведомления поверх страницы. Написана с нуля под наши технологии: буфер клеток вместо прямой записи в `term`, события и фокус вместо блокирующих циклов, рамки и значки из символов нашего шрифта, темы и клавиши настраиваются, несколько программ работают одновременно.

## Слои

```
программа (виджеты)  ->  ui.runtime (фокус, события, слои, таймеры, анимации)  ->  ui.cells (буфер клеток)  ->  вывод
                                                                                                    ui.out_pixel (CC: Graphics, свой шрифт, Unicode)
                                                                                                    ui.out_text (обычный терминал, term.blit)
оболочка ui.shell: свой runtime на каждую программу + верхняя полоса + подвал + список программ
```

- **`ui.cells`**: буфер клеток (символ Unicode, цвет текста, цвет фона), отсечение, сдвиг, прямоугольник изменений, `blit` между буферами, затемнение по таблице (под диалогом).
- **Выводы** сравнивают буфер с тем, что на экране, и отправляют только изменившиеся клетки. `out_text`: одна строка клеток это один `term.blit`; символы вне набора CC заменяет `ui.charmap` (рамки на `+ - |`, русские буквы на латинские по одной на клетку, чтобы сетка не ломалась). `out_pixel`: глифы нашего шрифта (Monocraft 6x9) рисуются в поверхность `cgl`, показ делает `cgl` (изменённая область, строки через `string.char`). Любые символы, кириллица, рамки без замен.
- **Цвета** это 16 мест палитры темы (роли: `BG PANEL RAISED LINE MUTED TEXT BRIGHT ACCENT ACCENT_DIM OK WARN ERR INFO SEL_BG SEL_FG SHADOW`). Смена темы это смена палитры (без перерисовки клеток).

## Темы

`cubeos` (чёрный с бирюзовым, как в старом CubeOS), `dark`, `light`, `retro` (зелёный люминофор: развёртка и мерцание, только в пикселях), `hacker` (рамки ASCII), `amber`, `contrast`. Тема это 16 цветов, стиль рамок, эффекты (`scanlines`, `flicker`) и таблица затемнения. `theme.get(имя):derive({border: "double"})` делает копию с другой рамкой. Свои темы: `theme.register(theme.Theme(имя, [16 цветов "#rrggbb"], {border, effects, dark}))`.

## Рамки

Стили `single`, `double`, `rounded`, `heavy`, `dashed`, `ascii`, `block`, `none`; свой стиль это таблица символов (`tl tr bl br h v lt rt tt bt x`, необязательно `top bottom left right`): `border.register("моя", {...})`, пропущенные ключи берутся из `single`. Рамка элемента: свойство `border` у `Frame`, иначе рамка темы. Заголовок, выравнивание заголовка, заливка внутри, разделители с тройниками.

## Клавиши

Элементы понимают действия (`up down left right enter back tab home end page_up page_down delete backspace menu help`), а какие клавиши к ним привязаны, решает раскладка: `arrows` (стрелки), `wasd`, `vim`; `keymap:bind("back", "q")` добавляет свою привязку. В полях ввода буквенные привязки отключаются: буквы остаются буквами (иначе WASD мешал бы печатать). Подвал страницы строится из подсказок сфокусированного элемента и его родителей. Esc привязан и по имени `escape`, и по кодам 256 и 1: в разных сборках таблица `keys` отличается.

## Элементы

| Модуль | Элементы |
|---|---|
| `ui.widget` | `vbox`, `hbox` (gap, padding, align, justify, grow, `width/height: "fill"`), `frame`, `label` (перенос, обрезка), `spacer`, `separator` |
| `ui.controls` | `button` (solid, box, flat; вспышка при нажатии), `checkbox`, `switch`, `slider` (мышь, перетаскивание), `input` (Unicode, пароль, прокрутка, мигающий курсор), `progress` (доли клетки, неопределённый), `spinner` |
| `ui.lists` | `list` (прокрутка, плавная полоса выбора, значки и подсказки в строках), `table_view`, `tabs`, `tab_view`, `text_view`, `dropdown` (стрелки или список), `popup_menu` |
| `ui.dialogs` | `message`, `confirm`, `prompt`, `toast` |

Раскладка в два прохода (`measure`, `layout`). Кнопки, флажки и переключатели не растягиваются поперёк ряда (`stretch: false`).

## Среда (`ui.runtime`)

- Фокус: Tab и Shift+Tab по кругу, стрелки между элементами по геометрии, клик. Модальный слой ограничивает фокус.
- События: `ui:handle(имя, a, b, c)` принимает события CC (`key`, `char`, `mouse_click`, `mouse_drag`, `mouse_up`, `mouse_scroll`, `term_resize`). Среда не блокируется: диалоги и меню это слои поверх страницы, при закрытии страница восстанавливается из буфера.
- Слои: `open_overlay(виджет, {modal, dim, dismiss, anchor, pop, shadow})`. Модальный слой затемняет страницу, Esc или клик вне закрывают.
- Время: `ui:tick(dt)`; `ui:after`, `ui:every` (таймеры), `ui:animate(объект, поле, значение, секунды, кривая)` на кривых `cgl.anim`, `ui:play(анимация)`. Переключатель `animations` и множитель `speed`. Цикл `runtime.run(ui)` ждёт событие и тикает только пока есть анимации и таймеры (в покое процессор не жжётся).
- Сочетания на всю среду: `ui:hotkey("ctrl+q", fn)`.

## Оболочка (`ui.shell`): несколько программ

Каждая программа это отдельная среда со своим буфером, фокусом, таймерами и анимациями. Невидимые программы продолжают работать: секундомер, плеер, загрузка в фоне не останавливаются. Верхняя полоса объединяет панель задач и строку состояния: слева кнопка списка программ и вкладки (значки, если названия не помещаются), справа виджеты программ и часы. Программа добавляет свой виджет: `app:add_bar_item({text: () => "◎ 00:12", priority: 60, on_click: fn})`; он виден из любой другой программы, при нехватке места пропадают малоприоритетные. Уведомление от скрытой программы помечает вкладку. Переход между программами скользит (`animations`).

Клавиши оболочки: Alt+→/← листают, Alt+1..9 переход по номеру, Alt+W закрыть, F9 или Alt+Space список программ. Касание монитора (`monitor_touch`) работает как нажатие мыши.

## Заставки (`ui.toys`)

Цифровой дождь, аквариум, трубы, снегопад, DVD-логотип, звёзды, «Жизнь», большие часы, бублик. Каждая это элемент, оживающий по таймеру; цвета берутся из темы (в `hacker` дождь зелёный). В демо они запускаются как программы.

## Запуск

```cubic
import ui
out = ui.open_out({})                                  # пиксели, если есть CC: Graphics, иначе обычный терминал
sh = ui.new_shell(out, {theme: ui.theme.get("cubeos")})
sh:register({id: "hello", name: "Привет", icon: "◆", launch: (app) => app:set_root(ui.label("Привет, мир"))})
sh:launch("hello")
sh:run()
```

В игре: `/repo/game/ui_demo.lua [pixel|text] [monitor=имя] [theme=имя] [keys=arrows|wasd|vim]`. Перед запуском лаунчер компилирует модули по одному с передачей управления (иначе «Too long without yielding» на медленном CC).

## Что ещё не сделано

- Свойство плотности (`compact`, `normal`, `comfortable`) есть в теме, но элементы пока его не читают.
- Выделение и буфер обмена в поле ввода, многострочное поле, перетаскивание элементов, подсказки по наведению.
- Проверка в настоящем CC: скорость кадра, вид `retro` (развёртка и мерцание), шрифт Monocraft для значков (недостающие значки заменены на имеющиеся).
- Оконный режим (GUI) на том же дереве элементов, но с пиксельными окнами и перетаскиванием; движение окон со следом (см. идеи в дорожной карте).
- Интеграция оболочки с ядром (программы как процессы ядра, права, фокус ввода ядра).
