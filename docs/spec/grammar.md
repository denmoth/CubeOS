# Грамматика и семантика Cubic 0.1.0

Статус: **реализовано** в `src/cubic` (компилятор 0.1.0). Здесь описано то, что действительно работает. Что обещано в [language-cubic.md](language-cubic.md), но ещё не сделано, перечислено в конце.

Пометка **[решение]** означает выбор, сделанный при реализации; он подлежит пересмотру автором.

## Лексика

- Блоки по отступам (только пробелы, табуляция в отступе запрещена). Отступ любой глубины, но согласованный.
- Комментарии `#` до конца строки.
- Продолжение строки: `\` в конце строки; внутри `()`, `[]`, `{}` переводы строк игнорируются.
- Числа: `42`, `1_000`, `3.14`, `.5`, `1e3`, `0xFF`.
- Строки: `"..."`, `'...'`, `"""..."""` (многострочные), `r"..."` (без escape), `f"..."` (подстановки).
  Escape: `\n \t \r \a \b \f \v \0 \\ \" \' \xHH \u{HHHH}` и `\` перед переводом строки.
- f-строки: `f"x = {x + 1}"`, `{{` и `}}` дают скобки. В выражении внутри нельзя использовать тот же тип кавычек, что снаружи, и обратную косую черту.
- Ключевые слова: `and or not if elif else while for in def return break continue pass class import from as export try except finally raise lua let const override is true false nil`.
  Слова `range` и `step` контекстные (ключевыми не являются). После `.`, `?.` и в ключах словаря можно использовать любые слова, в том числе ключевые.
- Имена, начинающиеся с `__`, зарезервированы компилятором. Имена, совпадающие с зарезервированными словами Lua (`end`, `local`, `then`, `repeat`...), разрешены: компилятор переименовывает их сам.

## Грамматика (EBNF)

```
module      = { statement } ;
statement   = if | while | for | funcdef | classdef | try | export | simple NEWLINE ;
suite       = ":" ( NEWLINE INDENT statement { statement } DEDENT | simple NEWLINE ) ;

if          = "if" expr suite { "elif" expr suite } [ "else" suite ] ;
while       = "while" expr suite ;
for         = "for" NAME [ "," NAME ] "in" ( range | expr ) suite ;
range       = "range" ( "[" | "(" ) expr "," expr ( "]" | ")" ) [ "step" expr ] ;
funcdef     = "def" NAME "(" [ params ] ")" suite ;
params      = param { "," param } [ "," "*" NAME ] | "*" NAME ;
param       = NAME [ "=" expr ] ;
classdef    = "class" NAME [ "(" expr ")" ] suite ;
try         = "try" suite { "except" [ expr ] [ "as" NAME ] suite } [ "finally" suite ] ;
export      = "export" ( funcdef | classdef | import | let | const | assign ) ;

simple      = "return" [ exprlist ] | "break" | "continue" | "pass"
            | "raise" [ expr ]
            | import | from
            | let | const | override
            | LUABLOCK
            | assign | augassign | expr ;
import      = "import" path [ "as" NAME ] ;
from        = "from" path "import" NAME [ "as" NAME ] { "," NAME [ "as" NAME ] } ;
path        = module path ("ui.widgets") | "./x/y" | "../x" | "/abs/x" | "$alias/x" ;
let         = "let" NAME { "," NAME } [ "=" exprlist ] ;
const       = "const" NAME "=" expr ;
override    = "override" NAME "=" expr ;
assign      = target { "," target } "=" exprlist ;
augassign   = target ( "+=" | "-=" | "*=" | "/=" | "//=" | "%=" | "**=" | "..=" ) expr ;
target      = NAME | postfix "[" expr "]" | postfix "." NAME ;

expr        = coalesce [ "if" coalesce "else" expr ] ;
coalesce    = or { "??" or } ;
or          = and { "or" and } ;
and         = not { "and" not } ;
not         = "not" not | comparison ;
comparison  = concat [ cmpop concat ] ;           (* цепочки a < b < c запрещены *)
cmpop       = "==" | "!=" | "<" | "<=" | ">" | ">=" | "in" | "not" "in" | "is" | "is" "not" ;
concat      = add [ ".." concat ] ;
add         = mul { ( "+" | "-" ) mul } ;
mul         = unary { ( "*" | "/" | "//" | "%" ) unary } ;
unary       = "-" unary | pow ;
pow         = postfix [ "**" unary ] ;
postfix     = primary { call | index | "." NAME | "?." NAME | ":" NAME call } ;
call        = "(" [ expr { "," expr } [ "," ] ] ")" ;
index       = "[" expr "]" ;
primary     = NUMBER | STRING | FSTRING | "true" | "false" | "nil" | NAME
            | "(" expr ")" | list | dict | lambda | "lua" "(" STRING ")" ;
list        = "[" [ expr { "," expr } [ "," ] ] "]" ;
dict        = "{" [ entry { "," entry } [ "," ] ] "}" ;
entry       = ( NAME | STRING | NUMBER ) ":" expr | "[" expr "]" ":" expr ;
lambda      = NAME "=>" expr | "(" [ NAME { "," NAME } ] ")" "=>" expr ;
```

Блок `lua:` (сырой Lua) распознаётся лексером: строка `lua:` и вложенные строки глубже неё становятся одним токеном `LUABLOCK`.

Приоритеты операторов (от слабого к сильному): `if/else`, `??`, `or`, `and`, `not`, сравнения, `..`, `+ -`, `* / // %`, унарный `-`, `**`, постфиксные операции.

## Семантика

### Значения и истинность [решение]

- Значения те же, что в Lua. `nil`, `true`, `false` пишутся строчными. `None`/`True`/`False` нет.
- Ложны только `nil` и `false`. **`0` и `""` истинны** (как в Lua, не как в Python).
- `[a, b]` это таблица `{a, b}`, `{k: v}` это таблица с ключами. Нумерация **с 1**.
- Если последний элемент списка это вызов функции, он усекается до одного значения.

### Переменные и области видимости [решение]

- Переменные видны во всей функции, как в Python: присваивание внутри `if`, `while`, `for` и `try` объявляет переменную на уровне функции (модуля).
- Присваивание **не создаёт глобалов**. Если имя уже есть в охватывающей функции (в том числе в модуле), присваивание меняет **её** (как в Lua, в отличие от Python). Иначе имя становится новой локальной.
- `let x = ...` всегда создаёт новую переменную в текущем блоке (затенение). `const X = ...` то же, но присвоить повторно нельзя.
- Переменная цикла `for` существует только в цикле и создаётся заново на каждой итерации (замыкания видят своё значение).
- Чтение необъявленного имени это обращение к глобалу Lua (`print`, `fs`, `term`, `peripheral`...).
- Ограничения Lua: не более 200 локальных переменных в функции и 60 внешних переменных на замыкание (проверяется только первое).

### Защита встроенных имён [решение]

- Нельзя присвоить, объявить или определить (`=`, `def`, `class`, `import`, `let`, `const`) имя из ядра Lua и встроенных функций Cubic (`print`, `type`, `pairs`, `tostring`, `math`, `string`, `copy`, `len`, `Error`...): ошибка компиляции. Для замены есть `override name = value`.
- Имена API CC: Tweaked (`term`, `fs`, `keys`, `colors`, `window`, `read`...) разрешены, но компилятор предупреждает, что имя скрывает глобальный API.
- Параметры и переменные цикла с такими именами дают предупреждение.

### Операторы

- `+ - * / %` числовые. `%` как в Lua (знак делителя, совпадает с Python). `//` это `math.floor(a / b)`, `**` это `^`.
- Строки склеиваются `..`, а не `+` [решение]. Есть f-строки.
- `==`, `!=`, `<`... `is` и `is not` равны `==` и `!=` (идентичности нет).
- `a in b`: если `b` строка, подстрока; если таблица с элементами в массиве, наличие значения; иначе наличие ключа. `not in` отрицание.
- `a ?? b` это `a`, если `a` не `nil`, иначе `b` (`false` и `0` сохраняются).
- `a?.b` даёт `nil`, если `a` равно `nil`. Остаток цепочки не пропускается: пишите `a?.b?.c` [решение].
- Условное выражение `x if c else y`.
- `len(x)`: длина строки или таблицы (для таблицы без массива число ключей).

### Функции

- `def f(a, b=2, *rest)`. Значения по умолчанию вычисляются **при каждом вызове** (нет ловушки изменяемых значений Python). `rest` это таблица `{...}`.
- Лямбды `x => x * 2`, `(a, b) => a + b`: только выражение.
- Именованные аргументы, распаковка `*args` пока не поддерживаются.

### Классы [решение]

- `class A(Base):` с методами `def name(self, ...)` (явный `self`), полями `name = value`, конструктором `def init(self, ...)`.
- Создание `A(args)`. Наследование одиночное; методы базы доступны, `Base.init(self, ...)` вызывается явно. Метаметоды (`def __tostring(self)`, `__eq`, `__add`...) наследуются.
- **Вызов метода пишется через `:`: `obj:method(x)`** (как в Lua), точка `.` это поле или функция без `self`. Это связано с тем, что объекты CC (периферия, дескрипторы файлов) вызываются через точку, а различить на этапе компиляции их нельзя.
- В теле класса допустимы только `def`, присваивания полей, `pass` и строка-описание.
- `isinstance(obj, Class)` проверяет принадлежность классу или предку.

### Исключения [решение]

- `raise value` бросает любое значение; `raise` без значения внутри `except` перебрасывает текущую ошибку.
- `try / except T as e / finally`. Подходящий обработчик выбирается по `isinstance`. Ошибки Lua и строки автоматически оборачиваются в объект `Error` (поле `message`), поэтому `except Error as e` ловит всё.
- Встроенный класс `Error`; свои ошибки наследуются от него (`class FileError(Error)`). Без подходящего обработчика ошибка перебрасывается.
- `return`, `break`, `continue` внутри `try`/`except` работают. Внутри `finally` запрещены.

### Модули

- Файл это модуль; значения для внешнего мира помечаются `export` (`export def`, `export class`, `export x = 1`, `export const`, `export import`) и только на верхнем уровне.
- `import ui` / `import ui.widgets` / `import ./utils` / `import ../x` / `import /abs/x` / `import $alias/x [as name]`. Имя по умолчанию это последний сегмент пути.
- `from path import a, b as c`.
- Сам поиск и загрузка модулей выполняет загрузчик (его функция `import(путь)` передаётся при загрузке модуля). В ОС это будет VFS; в тестах возвращается заглушка.

### Вставки Lua

- `lua:` с блоком копируется в вывод как есть. Локальные переменные Cubic доступны по тем же именам.
- `lua("выражение")` это выражение, вставляемое как есть.

### Диапазоны

`for i in range[a, b)` с математическими скобками: `[` и `]` включают границу, `(` и `)` исключают. Необязательный `step n` (может быть отрицательным). Границы и шаг предполагаются целыми числами. Диапазон существует только в заголовке `for` (в 0.1.0).

### Циклы

- `for x in e` перебирает значения таблицы (до первого `nil`), символы строки или значения, которые возвращает функция-итератор.
- `for k, v in e` перебирает пары таблицы (для массива это индекс и значение, для словаря ключ и значение; порядок словаря не гарантируется) или функцию-итератор.
- `continue` реализован через `goto` Lua 5.2; **в игровом CC нужно проверить поддержку `goto`** (в CraftOS-PC она есть).

## Не реализовано (запланировано)

Описано в [language-cubic.md](language-cubic.md), но в 0.1.0 нет: строгая типизация и директивы `#!strict`/`#!loose`, аннотации типов, `.cuh`, срезы `a[1:2]`, генераторы списков, именованные аргументы, распаковка `*rest` в присваивании и вызове, `match`, декораторы, `with`, `async/await`, форматирование в f-строках (`{x:.2f}`), `super()`, `--keep-comments`, `--minify`, карта `.map` в виде файла.
