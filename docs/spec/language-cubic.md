# Спецификация языка Cubic (черновик)

Cubic ("кубик") это язык с питоноподобным синтаксисом (блоки по отступам), транспилируемый в Lua. Расширение файлов `.cub`.

Статус: **черновик**. Грамматика не зафиксирована.

## Принципы

- Блоки по отступам, `:` вместо `then`/`do`/`end`.
- Результат это обычный Lua, который работает на скорости Lua. Виртуальной машины нет.
- Полная совместимость с Lua-таблицами и API CC: `.cub` и `.lua` вызывают друг друга.
- **Нумерация с 1**, как в Lua.
- Комментарии `#`.

## Типы и числа

- Один числовой тип `num` (в CC нет целых). `int` не вводим (решение D36).
- Деление: `/` дробное, `//` целочисленное (`math.floor(a / b)`).
- Остальные типы: `str`, `bool`, `list[T]`, `dict[K, V]`, `T?` (может быть nil), функции, классы, `any`.

## Строгий режим

Директивы-комментарии, действуют до следующей директивы:

```
#!strict      # включить строгую проверку типов
#!loose       # выключить
```

Можно оформить и блоком:

```
loose:
    # здесь ленивый код
```

- В `loose` участках всё имеет тип `any` для строгого кода (вызывать можно, ошибок нет).
- Проверка только при компиляции, на скорость не влияет.
- Необязательная проверка типов во время выполнения на границах (rednet, файлы).
- Нужны описания типов CC API (аналог `.d.ts`), генерируются из документации CC.

## Диапазоны

Математическая запись интервалов с префиксом `range`:

```
for i in range[1, 5]: ...      # 1 2 3 4 5
for i in range[1, 5): ...      # 1 2 3 4
for i in range(1, 5]: ...      # 2 3 4 5
for i in range(1, 5): ...      # 2 3 4
for i in range[0, 10) step 2: ...
```

Срезы: `a[2:4]` означает `range[2, 4]` (включающий). Явный вариант: `a[range[2, 4)]`.

## Возможности языка

- Блоки по отступам, `+=`, `-=`, `!=`, `and/or/not`, `in`, `is`.
- f-строки: `f"Привет, {name}!"`.
- Списковые выражения: `[x*2 for x in xs if x > 0]`.
- Распаковка: `a, b = pair`, `first, *rest = items`.
- Аргументы по умолчанию и именованные: `draw(x, y, color=white)`.
- Классы с наследованием.
- Лямбды: `x => x * 2`.
- `?.` и `??`.
- `match` (сопоставление с образцом).
- Декораторы и `with`.
- `async/await` поверх корутин.
- Необязательные подсказки типов.

Пример:

```
import ui

class Notes(ui.Window):
    def init(self):
        self.items = []

    def add(self, text):
        if text == "": return
        self.items += [text]
        self.redraw()

    async def sync(self):
        res = await http.get("https://example.com/notes")
        for line in res.lines():
            print(f"> {line}")
```

## Копирование

Встроено без импорта:

```
b = copy(a)          # поверхностная копия
c = deepcopy(a)      # глубокая, обрабатывает циклические ссылки, сохраняет классы
d = a.copy()         # метод
```

Причина: в Lua присваивание таблицы это ссылка.

## Защита имён

- Присвоение встроенному имени это ошибка.
- `override name = value` для явной подмены (нужно разрешение в песочнице).
- `const X = 1` для констант.

## Исключения

```
try:
    risky()
except FileError as e:
    log(e)
finally:
    cleanup()

raise MyError("текст")
```

Реализация через `pcall`/`xpcall`, типизированные ошибки, трассировка со ссылками на строки `.cub`.

## Вызов методов

- Своим классам компилятор сам подставляет `:` для методов.
- Для объектов Lua/CC по умолчанию `a.b()` остаётся точкой (периферия CC так и работает).
- Явный Lua-стиль `obj:method()` допускается.

## Нативные вставки Lua

```
lua:
    local w, h = term.getSize()
    for i = 1, h do ... end
```

- Блок копируется в вывод как есть (лексер не разбирает его).
- Переменные Cubic доступны по тем же именам (локальные не переименовываются).
- Строчная форма: `x = lua("a + b")`.
- Тип вставки `any`, если не указан.
- Минификатор не трогает идентификаторы внутри вставок.

## JSON

Встроенный модуль `json`: `encode`, `decode`, `pretty`. Для конфигов ОС используется JSON5 (см. [../03-file-formats.md](../03-file-formats.md)).
