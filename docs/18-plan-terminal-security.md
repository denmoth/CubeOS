4. ✅ **Ctrl+C, Ctrl+Shift+C/V, Ctrl+T в терминале** (D222). Двойного Ctrl+C нет (владелец часто жмёт его много раз подряд). Что приходит в игре на Ctrl+V (событие `paste` или клавиша), проверить журналом ввода.

## Проверить в игре (ничего из этого в игре ещё не проверено)

После `bash tools/deploy_game.sh` нужен `/repo/game/install_dev.lua` и Ctrl+R (менялись `sys/startup.lua`, `sys/boot/*`, появились `sys/boot/diskboot.lua` и `sys/cfg/locale.conf`).
1. Загрузка: подсказка внизу «Del: menu»; Delete открывает меню; пункт «CubeOS (input log)»; пункт CraftOS показывает предупреждение и спрашивает `y`, потом пароль.
2. Дискета со `startup.lua` в дисководе: система грузится как обычно (в `boot.log` строка про выключенную загрузку с дискет ROM); `disk list`; `sudo disk trust`, `sudo disk boot trusted`, перезагрузка: дискета стартует вместо системы.
3. Вход: `pin set` в терминале, перезагрузка, вход по PIN; 5 неверных PIN, потом пароль; `remember 10`.
4. Терминал: набрать `dir /sduawhd` по буквам (без ошибок на экране), Ctrl+C сбрасывает строку, выделить мышью и Ctrl+C копирует, Ctrl+Shift+V вставляет, удержание Ctrl+T без программы перезапускает оболочку, Ctrl+A/Ctrl+Z/Ctrl+Backspace в строке.
5. Русская раскладка Windows: буквы появляются (кириллица видна только в пиксельном терминале); Ctrl+Shift (нажать и отпустить) меняет раскладку, Ctrl+Shift+C нет.
6. `help`, `help ls`, `ls --help`, `help time`, `locale set ru` (пиксельный терминал), `fetch`, `timedatectl set-timezone Europe/Moscow`, `date`, `logs` (время местное).
7. `sudo ls /cubeos/var/log`, `inputlog on`, что-нибудь набрать, `logs input` (пароли не видны), `inputlog off`.

## Справка для следующего исполнителя

- Логи игры читать с диска: `D:\PrismLauncher\instances\CubeOS Dev\minecraft\saves\Новый мир\computercraft\computer\0\cubeos\var\log`.
- Выкатка: `bash tools/deploy_game.sh`; после изменений в `sys/` владелец запускает в игре `/repo/game/install_dev.lua`.
- Время: `timedatectl set-timezone Europe/Moscow` (или `+03:00`, или страна: `japan`), `timedatectl list-timezones [страна]`; журналы пишут местное время.
- Переводы: новые строки справки находит `python tools/lang_strings.py`, переводы в `tools/lang_data.py`, файлы `assets/lang/*.lang` пишет `python tools/gen_lang.py`. Пояса обновляются `python tools/gen_tzdata.py` (после `pip install -U tzdata`).
- Новая встроенная команда: функция в `lib/cush/builtins.cub` и запись в `lib/cush/commands.cub`, иначе падает тест `lib_cush_help`.
