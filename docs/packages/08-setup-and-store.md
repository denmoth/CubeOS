# Установка системы и магазин

## Установка на чистый компьютер с интернетом

Одна команда в CraftOS:

```
wget run https://raw.githubusercontent.com/<аккаунт>/cobble/main/install.lua
```

`install.lua` это маленький самостоятельный загрузчик (простой Lua, 15.8 КБ):
1. Проверяет CC (версия, `http` включён), считает место на диске.
2. Скачивает `index.json5` Cobble и пакет `cubeos.setup` вместе с зависимостями (Cubic runtime, логотип, `cubeos.stew` и всё, что нужно
   самому `stew`: `cpk`, `deflate`, `json`...). Каждый `.cpk` проверяется по размеру и sha256.
3. **Распаковка без готового deflate.** В CC нет библиотеки распаковки, а `.cpk` сжат deflate. Поэтому в `install.lua` свои маленькие
   sha256, inflate (по puff.c), JSON5 и чтение `.cpk`. Им он распаковывает скачанные пакеты во временную папку `/.cubeos-setup`,
   поднимает там мини-загрузчик модулей (как `sys/boot/pkgload.lua`) и дальше работает уже **настоящий** `stew` и экраны установщика
   (`lib/setup`), никаких копий `stew` в загрузчике нет.
4. Экраны установщика (ниже) в текстовом режиме, чтобы влезать на любой компьютер; на цветном экране он цветной.
5. Ставит выбранное через `stew` в одной транзакции (обрыв = откат, повторный запуск продолжает), затем `s:clean()` убирает кэш каталога
   (около 60 КБ), создаёт администратора и удаляет временную папку.
6. Перезагрузка в CubeOS.

Запуск:

```
wget run <url install.lua>                      # из интернета (по умолчанию каталог Cobble)
wget run <url install.lua> <url каталога>       # другой каталог
install.lua --from /disk/packages               # без интернета: папка с index.json5 и .cpk (build/packages)
```

Ещё ключи: `--root <папка>` (куда ставить, по умолчанию `/`), `--keep` (не удалять временную папку), `--events <файл>` (сценарий нажатий
клавиш для проверок). Проверка целиком на чистом компьютере эмулятора: `tools/setup_e2e.sh` (id 960, минимальный набор из
`build/packages`), снимки экранов: `tools/setup_shots.sh` (`build/setup_*.png`).

## Экраны установщика

1. **Привет:** язык, лицензия, что найдено (размер диска, монитор, модем, динамик).
2. **Профиль:** минимум (текст и терминал) / рабочий стол / всё / вручную. У каждого размер и «влезает / не влезает».
3. **Вручную:** дерево категорий (07-system-split.md) с галочками и размерами. Обязательные (E) отмечены и не снимаются, зависимости
   добавляются сами. Внизу постоянно счётчик «занято X из Y».
4. **Опции пакетов**, у которых они есть (04-installers.md), с умолчаниями.
5. **Хранение:** компактно (всё сжато) / быстро (всё распаковано) / авто (по умолчанию). Под каждым вариантом итоговый размер.
6. **Если не влезает:** предложить снять галочки с `optional`, перейти на «компактно» или подключить второй компьютер (расширитель):
   пакеты `optional` ставятся на него. Это шаг 8 плана, в первой версии установщика только первые два варианта.
7. **Пользователь:** имя, пароль, аватар (как в CDE).
8. **Сводка** и установка с прогрессом по пакетам.

## Магазин

Приложение CDE поверх `stew` (тот же API, что у `stew` в терминале).

- Главная: подборки, обновления, категории.
- Поиск по всем источникам, фильтр по источнику (Cobble, PineStore, свои).
- Карточка пакета: иконка, скриншот, описание, размер, разрешения, источник и доверие, зависимости, версии.
- Кнопки: установить (с опциями), обновить, удалить, запустить, попробовать без установки.
- Очередь установки с прогрессом, «обновить всё».
- Вкладка «Мои пакеты»: установленное, способ хранения у каждого (сжато / распаковано), занятое место.
- Вкладка «Публикация» (если стоит `cubeos.stew-publish`): мои пакеты в Cobble, состояние PR, «опубликовать папку».

Пакеты PineStore помечены «программа CraftOS» и запускаются в окне терминала.

## Название магазина (решает владелец)

Каталог уже Cobble, менеджер `stew`. Варианты для приложения:

| Имя | Почему |
|---|---|
| **Quarry** | каменоломня: место, где добывают булыжник (cobble). Коротко, по-майнкрафтовски, не повторяет имя каталога. Рекомендую. |
| Cobble Store | просто и понятно, но длинно и повторяет каталог |
| Mason | каменщик: тот, кто строит из камня |
| Crate | ящик с вещами |
| Bazaar | рынок, понятно без перевода |

Пока имя не выбрано, в коде и документах пакет называется `cubeos.store`.
