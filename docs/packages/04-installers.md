# Установщики пакетов

Два уровня. Простой пакет ставится без своего кода, сложный может всё, что ему разрешено.

## Уровень 1: декларативно (большинство пакетов)

Всё из `contributes` и `options` манифеста (02-manifest.md). `stew` сам:

- регистрирует приложения в меню, значки, ассоциации файлов, автозапуск, службы;
- раскладывает темы, шрифты, обои, языки, музыку туда, где их ищет система;
- записывает настройки по умолчанию (не трогая уже изменённые пользователем);
- при удалении убирает ровно то, что добавил (список хранится в базе установленных).

### Опции

Описываются в манифесте и показываются:
- на рабочем столе окном установки (шаг на опции, как экраны в 08-setup-and-store.md);
- в терминале вопросами `stew install`;
- без вопросов (`--yes`, профили установщика системы) берутся значения по умолчанию;
- явно: `stew install snake --opt packs=retro,calm --opt autostart=true`.

Виды: `bool`, `choice`, `multi`, `text`, `number`, `path`. У каждой опции `id`, `label`, `default`, по желанию `help`
и `when` (показывать, если другая опция имеет значение).

Выбранные значения хранятся в базе установленных и доступны пакету (`stew.options(id)`). `stew reconfigure <пакет>` спрашивает
заново и применяет.

Опция может включать необязательную часть пакета: `{ id: "hd", type: "bool", files: ["assets/hd/**"] }` означает, что файлы
ставятся только при включённой опции (место считается в плане).

## Уровень 2: скрипт `setup.lua` / `setup.cub`

Модуль возвращает таблицу с необязательными функциями:

| Функция | Когда | Пример |
|---|---|---|
| `ask(api)` | до скачивания основной части, после опций манифеста | свои шаги, проверка периферии |
| `install(api)` | после того как файлы на месте, до фиксации | создать данные, сгенерировать конфиг |
| `upgrade(api, from)` | при обновлении вместо `install` | перенести настройки старого формата |
| `remove(api)` | перед удалением | спросить, удалить ли сохранения |

`api` это ограниченный набор: опции, папки пакета (`api.dir`, `api.data`, `api.cfg`), чтение и запись в своих папках, вопросы
пользователю, прогресс, лог. Ядро, чужие папки и сеть только если пакет получил на это разрешение (`permissions`).

- Скрипт работает внутри транзакции: ошибка или `api.abort(причина)` откатывает установку целиком.
- Время ограничено (сторожевой таймер, скрипт должен уступать управление на долгих операциях).
- Скрипт из источника с доверием `user`/`adhoc` показывается в плане отдельной строкой «пакет запускает свой код установки».

## Установщик `.stp`

Остаётся как в 03-file-formats.md: самостоятельный файл для установки без менеджера (на чистый CraftOS). Внутри `.cpk` и тот же
манифест. Установщик самой CubeOS (08-setup-and-store.md) это частный случай.
